Pulsa <kbd>Ctrl</kbd>+<kbd>/</kbd> en Parley para ver esta lista en cualquier momento. En Mac, usa <kbd>⌘</kbd> donde pone <kbd>Ctrl</kbd>.

## Moverse

| Teclas | Qué hace |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Selector rápido: ve a cualquier servidor, canal o persona |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Canal anterior / siguiente |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Canal no leído anterior / siguiente |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Servidor anterior / siguiente |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Abrir tu bandeja de entrada |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Mensajes fijados |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Mostrar u ocultar la lista de miembros |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Ir a una fecha |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Ajustes de usuario |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Atrás / adelante (app de escritorio) |

## Mensajes

| Teclas | Qué hace |
|---|---|
| <kbd>Enter</kbd> | Enviar |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nueva línea |
| <kbd>↑</kbd> (con el cuadro vacío) | Editar tu último mensaje |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Ir al cuadro de mensaje |
| <kbd>Esc</kbd> | Cancelar una respuesta, o marcar el canal como leído |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Marcar todo el servidor como leído |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Negrita / cursiva / subrayado en la selección |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Tachado |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Código |

Empieza a escribir en cualquier sitio y tus palabras irán al cuadro de mensaje.

## Voz

| Teclas | Qué hace |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Silenciar o reactivar el micrófono |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Ensordecer o dejar de ensordecer |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Guardar un clip de la llamada |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Activar o desactivar el Modo streamer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Superposición en el juego (app de escritorio) |

## Cambiar los atajos

Abre **Ajustes de usuario → Atajos de teclado** para cambiar cualquiera de ellos o añadir una tecla de **Pulsar para hablar**. La app de escritorio también puede detectar algunos atajos mientras estás en otra app, como un juego.
