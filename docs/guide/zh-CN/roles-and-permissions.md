**身份组** 是你给成员贴的标签，比如*版主*、*艺术家*或*新人*。每个身份组都带有 **权限**，决定其成员可以做什么。身份组还可以有颜色和图标，显示在成员名字旁边。

服务器中的每个人都自动拥有 **@everyone** 身份组。它的权限就是所有人都能做的事。

![服务器设置中的身份组页面](shot:roles)

## 创建身份组

1. 打开 **服务器设置 → 身份组**，点击 **创建身份组**。
2. 给它起个名字，选一个颜色。还可以：
   - 设置 **身份组图标**（一个表情或一张小图片）
   - 在成员列表中 **将身份组成员与在线成员分开显示**
   - **允许任何人 @提及 此身份组**
   - **允许成员自行选择此身份组**
3. 开启它应有的权限。
4. 在 **成员** 标签页中添加成员，或在成员列表中右键单击某人并选择身份组。

**复制身份组** 会复制一个身份组，想做一个相似的身份组时很方便。

## 哪个身份组说了算

身份组按顺序排列，排在上面的身份组级别高于下面的。拖动它们，或使用 **上移** 和 **下移** 调整顺序。

- 成员只能管理比自己最高身份组更低的身份组。
- 当多个身份组的颜色冲突时，使用级别最高的身份组的颜色。

**以身份组视角查看服务器** 会准确地显示拥有该身份组的成员能看到什么，方便你检查设置。

## 权限

权限分为几组：常规、会员资格、文字、语音和工作室。其中最重要的一些：

| 权限 | 允许成员… |
|---|---|
| **管理员** | 做任何事，并跳过所有频道限制。请谨慎授予。 |
| **管理服务器** | 修改服务器的名称、图标和设置。 |
| **管理身份组** | 创建和分配比自己低的身份组。 |
| **管理频道** | 创建、编辑和删除频道。 |
| **踢出 / 封禁 / 禁言成员** | 管理成员。请参阅[管理](moderation)。 |
| **管理消息** | 删除和标注任何人的消息。 |
| **提及 @everyone** | 提醒整个服务器的人。 |
| **创建邀请** | 邀请新成员。 |
| **管理表情** | 添加表情、贴纸和音效。 |
| **管理活动** | 安排活动。 |
| **查看审核日志** | 查看谁改了什么。 |

> Tip: 先让 **@everyone** 可以阅读和聊天。再添加一个*版主*身份组，赋予踢出、禁言和管理消息权限。很少有人需要管理员权限。

## 频道权限

要把某个频道设为私密，或修改大家在某个频道中能做的事：

1. 右键单击频道，选择 **编辑频道**，再点 **权限**。
2. 开启 **私密频道**，除了你添加的身份组和成员，其他人都看不到它。
3. 或者使用 **添加身份组或成员**，把每项权限设为 **允许**（✓）、**拒绝**（✗）或 **继承**（/，即服务器范围的设置）。

分类也有权限。与所属分类一致的频道会显示 **已同步**；修改之后，**立即同步** 会让它重新与分类保持一致。

## 成员列表

**服务器设置 → 成员** 列出了所有人。你可以搜索、按身份组筛选、查看每个人是如何加入的，以及分配或移除身份组。你还可以一次选中多人，将他们踢出或封禁。

## 关联身份组

关联身份组会自动分配给关联了某个账号的人，比如 Twitch 订阅者。在 **集成** 中设置。
