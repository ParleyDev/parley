Parley 是和朋友、社区聊天的地方：文字聊天、语音和视频通话、直播舞台，还有音乐工作室。所有功能对所有人免费。

## 无需账号试一试

想先看看？打开 [app.runparley.com/try](https://app.runparley.com/try)，或在登录页点击 **无需账号试一试**。你会拿到一张访客通行证，直接进入演示服务器。

访客账号会在你离开一小时后被删除。想保留的话，点击横幅中的 **注册以保留**。你的消息、个人资料和服务器都会一并保留。

## 创建账号

1. 前往 [app.runparley.com/register](https://app.runparley.com/register)。
2. 输入你的邮箱，选一个 **用户名**：2 到 32 个字母、数字、`_` 或 `.`。别人可以通过它找到你。
3. 可以再加一个 **显示名称**。这是别人看到的名字，可以包含空格和大写字母。
4. 设置一个至少 8 个字符的密码，然后点击 **继续**。

Parley 会给你发一封邮件，里面有验证地址的链接。点击之前，你可以聊天，但不能创建服务器，也不能使用“发现”。如果没收到邮件，可以点应用顶部横幅中的 **重新发送**。

## 登录

你可以用以下任意一种方式登录：

- **邮箱或用户名加密码。**
- **通行密钥**：用指纹、面容或设备 PIN 登录，不用输入密码。在 **用户设置 → 账号** 中添加。
- **二维码。** 在电脑上，登录页会显示一个二维码。用已经登录的手机扫码，再点 **是，登录** 确认。

> Heads up: 只扫你自己屏幕上显示的 Parley 登录码。千万不要扫别人发给你的码，那会让*对方*以你的身份登录。

如果你开启了[双重验证](settings#account)，Parley 还会要求输入验证器应用里的 6 位验证码、备用码或安全密钥。

**忘记密码了？** 在登录页点击 **忘记密码了？**，Parley 会给你发一封邮件，里面有设置新密码的链接。

**有不止一个账号？** 点击你的头像，再点 **切换账号**，就可以添加其他账号并在它们之间切换。

## 在你的设备上使用 Parley

| 在哪里 | 怎么做 |
|---|---|
| **网页浏览器** | 前往 [app.runparley.com](https://app.runparley.com)。无需安装。你还可以通过用户设置中的 **安装应用** 把它添加到主屏幕或程序坞。 |
| **Windows、macOS、Linux** | 从 [runparley.com](https://runparley.com/#download) 下载桌面应用。它可以在后台运行，玩游戏时按键发言照样能用，还有游戏内覆盖层。 |
| **Android** | 从 [runparley.com](https://runparley.com/#download) 安装应用，即可收到推送通知，关屏后通话也不会中断。 |
| **iPhone 和 iPad** | 在 Safari 中使用 [app.runparley.com](https://app.runparley.com)，并通过 **添加到主屏幕** 来接收通知。 |

桌面应用会自动更新。更新准备好后会出现一个绿色箭头，点击 **重启以更新** 即可。

> Note: Parley 是开源的，任何人都可以运行自己的 Parley 服务器。应用会询问要连接哪台服务器：选择 **app.runparley.com**，或输入你所在社区自己的地址。之后可以在用户设置中通过 **切换服务器** 更换。

## 休息一下，或者离开

在 **用户设置 → 账号** 的 **账号移除** 下：

- **停用账号** 会让你在所有设备上登出，并隐藏你的账号。什么都不会被删除。想重新启用时，随时再登录就行。
- **删除账号** 会永久删除它。删除之前，你需要先移交或删除你拥有的服务器和应用，然后输入密码确认。

删除后，你有 **14 天** 可以反悔：只要登录并选择 **恢复我的账号**。之后，你的个人信息会被清除。你以前的消息会留在原处，但会显示为来自*已删除用户*。

你也可以不打开应用，直接在 [app.runparley.com/delete-account](https://app.runparley.com/delete-account) 删除账号。
