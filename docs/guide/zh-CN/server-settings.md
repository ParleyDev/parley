点击服务器名称打开服务器菜单，然后点 **服务器设置**。你只能看到你有权限修改的页面。所有者可以看到全部内容。它会在与用户设置相同的窗口中打开；在列表顶部的搜索框中输入即可找到某个页面。

![服务器设置中的服务器资料页面](shot:server-settings)

## 名称、图标和横幅

在 **服务器资料** 中：

- **图标**：一张方形图片，最大 8 MB。
- **服务器名称**：最多 100 个字符。**描述**：最多 300 个字符。
- **服务器横幅**：频道列表顶部的图片。按 16:9 裁剪；1920×1080 最理想。GIF、APNG 和 WebP 动图会保持动态。
- **系统消息频道**：Parley 欢迎新成员的地方。还可以提示成员挥手打招呼。
- **服务器规则**：最多 4,000 个字符。勾选 **成员必须先接受规则才能聊天**，让新成员先同意规则。
- 新成员的 **默认通知设置**，以及成员能否 **定时发送消息**。

选好图片后，拖动和缩放来调整取景。之后想重新调整，点击 **调整**。

这里还有：

- **服务器主题**：给服务器设置专属配色。成员可以选择是否显示。
- **服务器标签**：一个简短的标签和徽章，成员可以佩戴在名字旁边。
- **数据洞察**：有多少人加入并留下来、服务器有多活跃，以及哪些频道最受欢迎。

## 邀请他人

在服务器菜单中点击 **邀请他人**，即可获得一个可以分享的链接。在服务器设置的 **邀请** 中，你可以创建自定义邀请：

- **过期时间**：30 分钟到 30 天，或永不过期。
- **最大使用次数**：1 到 100 次，或不限次数。
- **授予临时成员资格**：成员登出时会自动离开，除非他们已被分配了身份组。

所有有效的邀请都会列出，可以用 **撤销** 取消某个邀请。列在“发现”中的公开服务器还可以拥有一个 **自定义链接**。

**访问**：想手动审核新成员，开启 **先审核新成员，再允许其聊天**，并写几个问题。申请会等你来 **批准** 或 **拒绝**。

## 频道和分类

- **创建频道** 在服务器菜单中，也可以点击分类旁边的 **+**。各种频道请参阅[频道](channels#kinds-of-channel)。
- 拖动频道和分类即可调整顺序。
- 右键单击频道并选择 **编辑频道**，可以设置：
  - 频道主题和 **慢速模式**
  - **年龄限制** 和 **剧透** 设置。年龄限制频道只对已确认年满 18 岁的成员开放，其他人看到的是锁定状态。对分类开启后，其中的每个频道都会受到限制。只有本人已获确认的人才能再将其关闭。
  - 语音频道：**用户上限**、视频和音频质量，以及 **端到端加密**
  - 论坛 **标签**
  - **权限**：请参阅[身份组和权限](roles-and-permissions#channel-permissions)

## 表情、贴纸和音效

| | 上限 | 文件 |
|---|---|---|
| **表情符号** | 每个服务器 100 个 | PNG、JPEG、GIF 或 WebP，小于 512 KB。名称为 2 到 32 个字母、数字或 `_`。 |
| **贴纸** | 每个服务器 60 个 | 小于 1 MB。320×320 像素效果最好。 |
| **音效板** | 每个服务器 48 个 | MP3、OGG、WAV、WebM 或 M4A，小于 512 KB（约 5 秒）。 |

成员可以在他们所在的任何服务器中使用你的自定义表情。

## 欢迎新成员

- **欢迎页面**：有人加入时显示的问候语，最多附带 5 个推荐频道。
- **新手引导**：给新成员的问题（“你为什么来这里？”）。每个答案都可以为他们分配身份组和频道，让大家看到与自己相关的内容。可以把问题设为 **必填**，或允许多选。
- **规则**：在服务器资料中设置。成员要先点击 **我同意** 才能发言。

## 服务器内的社区

在大型服务器中，可以把频道分组为[社区](channels#communities)。每个社区都有自己的页面和管理者。

- 点击频道列表中 **社区** 旁边的 **+** 即可创建。
- 打开它的页面并点击 **编辑**。你可以设置：
  - 图标、名称和简介
  - 一个网址
  - **关于** 部分和 **链接**
  - 由谁负责管理，以及包含哪些频道
- **添加页眉图片** 可以给页面加一张横幅：
  - 宽度 1600 像素或以上的宽图效果最好。
  - 点击 **调整** 选择 **填充** 或 **适应**，用对齐网格摆好位置，并调整缩放。
  - 预览会显示它在手机、笔记本电脑和宽屏上的样子。
- **删除社区** 位于编辑栏顶部。它也会删除该社区的频道及其中的消息。

## 让更多人找到你

- **发现**：把服务器列到“发现”中，附上分类、简介和横幅。会先由管理员审核。
- **小组件**：可以嵌入你网站的一个小窗口，显示谁在线，并带有 **加入** 按钮。
- **徽章**：可用于 README 或网站的实时“加入我们”徽章。

## 服务器模板

**服务器设置 → 服务器模板** 可以分享你服务器的设置（身份组、分类、频道、权限和一些设置），让别人建立一个一模一样的服务器。消息、成员和表情符号都不会被复制。

- **下载模板文件** 会把服务器当前的状态保存为一个 `.json` 文件。可以留作设置的备份，或发给别人。不需要链接。
- **分享链接**：为模板填写标题和描述，然后点 **生成模板**。链接保持不变；修改服务器后点击 **同步模板**，链接就会提供新的设置。**删除模板** 会让链接失效。

任何人都可以在任何 Parley 服务器上，通过 **添加服务器 → 使用模板**，用模板文件或链接创建服务器。请参阅[从模板开始](joining-servers#starting-from-a-template)。

打开模板链接的人可以看到它会设置哪些内容，并可以用它创建服务器或将其下载为文件。

## 移交或关闭服务器

这些在列表底部，只有所有者可以使用：

- **转让所有权** 会把服务器交给另一位成员。
- **删除服务器**：输入服务器名称和你的密码进行确认。改主意了？你有 **7 天** 时间可以在 **用户设置 → 账号** 中恢复它。
