## 发送消息

在底部的输入框中输入，然后按 <kbd>Enter</kbd>。想换行而不发送，按 <kbd>Shift</kbd>+<kbd>Enter</kbd>。

- 打错字了？在空输入框中按 <kbd>↑</kbd>，就能编辑你的上一条消息。
- 写了一半的消息会按频道分别保存。稍后回来，草稿还在。
- 一条消息最多 2,000 个字符。更长的内容可以一键作为文件发送。

## 格式

选中一段文字会出现一个小工具栏：**粗体**、*斜体*、下划线、删除线、代码和剧透。你也可以自己输入格式：

| 输入 | 得到 |
|---|---|
| `**bold**` | **粗体** |
| `*italic*` | *斜体* |
| `__underline__` | 带下划线的文字 |
| `~~strike~~` | 带删除线的文字 |
| `` `code` `` | `code` |
| `\|\|spoiler\|\|` | 点击后才显示的文字 |
| `# Big heading`（也可以用 `##`、`###`） | 标题 |
| `-# small print` | 灰色小字 |
| `> quote` | 引用（`>>>` 会引用其后的所有内容） |
| `- item` 或 `1. item` | 列表 |
| `[text](https://…)` | 自定义文字的链接 |

要插入一段代码块，在它的前一行和后一行各放三个反引号。在开头的三个反引号后面加上语言名称（`` ```python ``）即可显示语法高亮。代码块带有 **复制** 按钮。

键盘快捷键也能用：<kbd>Ctrl</kbd>+<kbd>B</kbd> 粗体，<kbd>Ctrl</kbd>+<kbd>I</kbd> 斜体，<kbd>Ctrl</kbd>+<kbd>U</kbd> 下划线，<kbd>Ctrl</kbd>+<kbd>E</kbd> 代码。

## 提及

- 输入 `@` 加名字即可提及某人。对方会收到通知，这条消息也会为对方高亮显示。
- `@` 还能找到身份组，以及 `@everyone`（频道里的所有人）和 `@here`（所有在线的人）。谁能使用它们由服务器决定。
- 输入 `#` 可以链接一个频道。

用 <kbd>↑</kbd> 和 <kbd>↓</kbd> 在建议中挑选，按 <kbd>Enter</kbd> 或 <kbd>Tab</kbd> 选定。

## 表情、贴纸和 GIF

消息框右侧的三个按钮分别打开 **GIF**、**贴纸** 和 **表情符号** 选择器。

- **表情符号：** 可以搜索，有你常用的表情、各服务器的自定义表情，还能选择肤色。或者输入 `:` 加名字，比如 `:tada`，然后从列表中挑选。
- Parley 在每台设备上都用同一种风格绘制表情，所以大家看到的都一样，包括旗帜，即使电脑自带的表情已经过时也没关系。
- 来自你任何服务器的 **自定义表情**，在你能发言的所有地方都能用。点击消息中的自定义表情，可以看到它来自哪里。
- **贴纸** 来自你所在的服务器。
- **GIF：** 可以搜索，有热门和分类。把鼠标悬停在 GIF 上，点击星标就能把它保存到 **收藏**。

## 反应

把鼠标悬停在消息上，从你最常用的表情中挑选，或点击 **添加反应** 打开完整的选择器。**添加超级反应** 会添加一个带动画的反应。

点击消息下方的反应即可加上你的一份，再点一次就撤回。把鼠标悬停在反应上可以看到谁添加了它，也可以在消息菜单中选择 **查看反应**。

## 回复、编辑和删除

- **回复** 会在你的消息上方引用原消息，并通知原作者。按 <kbd>Esc</kbd> 取消。
- **编辑消息** 可以修改你写的内容。编辑过的消息会显示 **（已编辑）**，点击它可以查看之前的版本。
- **删除消息** 会为所有人删除它。

点击回复上方的引用行,即可查看它所回复的消息。底部提示条中的 **返回** 或 <kbd>Esc</kbd> 会带你回到之前的位置。

## 消息菜单

右键单击消息，点击它的 **⋯** 按钮，或在手机上长按它。你会看到：

- **回复**、**转发**、**创建子区**
- **复制文本** 和 **复制消息链接**
- **标注消息**。标注的消息列在顶部栏的标注按钮下（<kbd>Ctrl</kbd>+<kbd>P</kbd>）。
- **收藏消息**：保存到你的[收件箱](notifications#your-inbox)，以后再看
- **提醒我**：20 分钟后、1 小时后、3 小时后、明天或下周
- **标记为未读**：稍后再回来看
- **翻译**（如果服务器提供），以及 **朗读消息**，把它读给你听
- **移除嵌入内容**，隐藏链接预览
- **举报消息**，针对任何违反规则的内容

## 文件、图片和视频

点击 **+** 再点 **上传文件**，或把文件拖到聊天中，或直接粘贴。

- 每条消息最多 10 个文件，通常每个 25 MB。你所在服务器的托管方可能允许更大的文件。
- 发送前，你可以 **标记为剧透** 或 **添加替代文字**：为使用屏幕阅读器的人提供的描述。
- 点击图片会以原尺寸打开。视频和音频可以直接在聊天中播放。

## 语音消息

点击 **+** 再点 **录制语音消息**。说完后发送或丢弃。听的人可以把速度调到 1.5× 或 2×。如果服务器开启了转写，他们还可以阅读文字。

## 投票

点击 **+** 再点 **创建投票**：

1. 写一个问题和 2 到 10 个选项。每个选项都可以带一个表情。
2. 选择大家能否选多个选项。
3. 选择投票持续多久，从 1 小时到一周，或者不设结束时间。
4. 点击 **发布投票**。

结果会实时更新。发起投票的人可以提前结束投票。

## 定时发送消息

写好消息后，右键单击 **发送** 按钮（手机上长按），选择 **定时发送消息**。选一个时间，比如 **明天上午**，或者选择 **自定义**。

你最多可以有 30 条定时消息。它们在你[收件箱](notifications#your-inbox)的 **已定时** 下，你可以在那里 **立即发送**、编辑或删除它们。

## 转发

**转发** 会把消息的副本发送到其他频道或给其他人。它会标有*已转发*，即使原消息被删除也会保留。

## 斜杠命令

在输入框开头输入 `/`，就能看到你可以使用的命令：

| 命令 | 作用 |
|---|---|
| `/shrug` `/tableflip` `/unflip` `/lenny` | 在你的消息中加上相应的颜文字 |
| `/me` | 以斜体发送你的消息，表示一个动作 |
| `/spoiler` | 把整条消息隐藏起来，点击后才显示 |
| `/tts` | 把你的消息朗读给正在查看该频道的所有人 |
| `/nick` | 更改你在此服务器中的昵称 |

服务器中的应用和机器人还会添加它们自己的命令。请参阅[应用和机器人](apps-and-bots)。

## 摘要

频道太热闹？顶部栏的 **摘要** 按钮会给出最近两天的快速摘要。摘要是自动生成的，依赖它之前请先核对原始消息。服务器可以关闭此功能。
