**录音室** 频道是你服务器里的音乐工作区。每个 **项目** 就是一首歌，有自己的多轨编辑器、录音、评论、版本和聊天。乐队成员可以一起现场录音，也可以有空时再各自添加声部。

![在工作室中打开的一个项目](shot:studio)

## 新建项目

打开一个录音室频道，点击 **新建项目**。给它起个名字，设定速度。你需要拥有 **创建项目** 权限。

已经在别的地方开始写一首歌了？**导入** 可以打开来自 Bitwig、Studio One、Cubase 等软件的 `.dawproject` 文件，以及 Parley 自己的 `.parley-project` 文件。

## 录音

1. 在 **音频** 面板中设置音频：你的输出和 **录音延迟**。点击 **测量**，让你的录音和节拍对齐。
2. 添加一条音轨：**音频** 音轨用于麦克风或乐器，**MIDI** 音轨可以使用内置的合成器、鼓组或采样器。
3. 预备音轨，然后按录音。**录制乐队** 会从播放头开始录下会话中的所有人；**单独录音** 只录你一个人。一条录音最长 30 分钟。

没有 MIDI 键盘？用电脑键盘弹奏：<kbd>A</kbd> 到 <kbd>K</kbd> 是白键，<kbd>Z</kbd> 和 <kbd>X</kbd> 切换八度。

## 编排和编辑

| 按键 | 作用 |
|---|---|
| <kbd>Space</kbd> | 播放或停止 |
| <kbd>Home</kbd> | 回到开头 |
| <kbd>L</kbd> | 开启或关闭循环 |
| <kbd>S</kbd> | 在播放头处分割片段 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | 复制 |
| <kbd>Q</kbd> | 量化（把音符吸附到网格） |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 撤销 / 重做 |
| <kbd>Tab</kbd> | 在编排视图和调音台之间切换 |

双击 MIDI 片段即可打开 **钢琴卷帘**。此外还有节拍器和预备拍、标记、速度变化，以及用于音量和效果的自动化轨道。

在 **调音台** 中，每条音轨都有音量、声像、独奏、静音、效果和发送。

## 效果

每条音轨、每条总线和主输出都有一个效果架：EQ（均衡器）、Filter（滤波器）、Compressor（压缩器）、Gate（噪声门）、Limiter（限制器）、Reverb（混响）、Delay（延迟）、Drive（失真）和 Chorus（合唱）。点击 **+ 效果** 添加一个。效果按从上到下的顺序处理；把鼠标悬停在某个效果上，可以移动或移除它。

![吉他的 EQ 和压缩器、贝斯的滤波器的效果窗口，在歌曲播放时并排打开](shot:studio-effects)

点击效果即可打开它的窗口。你想开多少个窗口都行，还可以把它们拖到任何位置；点击某个窗口可以把它置于最前。每个窗口都会显示效果在做什么：

- **EQ** 和 **Filter**：叠在声音频谱上的频率曲线。拖动曲线上的圆点来调整形状。在 Filter 上，上下拖动可以增减共振，也可以用鼠标滚轮。
- **Compressor**、**Gate** 和 **Limiter**：输入响度与输出响度的对应关系、一个表示你当前声音位置的圆点、最近几秒的电平，以及被压低了多少。
- **Reverb**：尾音的形状。**Delay**：每次回声逐渐消失的过程。**Drive**：失真曲线，以及处理前后的声音。**Chorus**：调制扫动。

歌曲播放时，这些视图以及 **入** 和 **出** 电平表会随声音变化。

修改设置的方法：

- 上下拖动旋钮。按住 <kbd>Shift</kbd> 可以精细调节。
- 使用鼠标滚轮或方向键。
- 在旋钮下方输入数值，比如 `2.5k` 或 `25%`。
- 双击旋钮可恢复默认值。

窗口标题栏中的电源按钮可以关闭和开启效果。箭头按钮会重置它的所有设置。

> Tip: 把两条音轨上的同类效果并排打开，比如吉他的 EQ 和贝斯的 Filter，然后播放歌曲。你可以看到它们各自占据的位置，从而给对方让出空间。

### 示例

以下示例都从效果的默认设置开始。调整时让歌曲一直播放，最好开启 **循环**，这样窗口里显示的就是你的声音。

**清理吉他或人声的低频。** 添加一个 **EQ**。把曲线上的 **C** 圆点向右拖，直到 **低切** 显示约 `90 Hz`；低于这个频率的隆隆声就没了，曲线后面的频谱会显示你去掉了什么。把 **M** 圆点拖到约 `2.5k`，再往上提几 dB，让这个声部更突出。

**让人声更平稳。** 添加一个 **Compressor**。把 **压缩比** 设为 `4:1`，然后一边看曲线上的圆点一边调低 **阈值**：当响亮的字越过拐点时，**GR** 电平表会显示它们被压低了多少。让最响的字压低约 3 到 6 dB，然后把 **补偿增益** 调高差不多的量，让这个声部和之前一样响。

**扫动滤波器。** 给合成器或鼓音轨添加一个 **Filter**，选择 **低通**。歌曲播放时，把曲线上的圆点从右向左慢慢拖动：随着截止频率降低，声音会越来越暗。上下拖动圆点，或在它上面滚动鼠标滚轮，可以调整 **共振**：数值越高，截止频率处的峰越尖锐、越有鸣响感。想让扫动成为歌曲的一部分，可以用[自动化轨道](#arranging-and-editing)把它录下来。

**消除嘈杂音轨在音符之间的嘶嘶声。** 在效果架最前面添加一个 **Gate**。留意指示灯：声部演奏时显示 **OPEN**，间隙中显示 **CLOSED**。调高 **阈值**，直到它在间隙中关闭，但在你想保留的最轻的音符上仍保持打开。

**给声部加上空间感。** 添加一个 **Reverb**，把 **混音** 设为约 `20%`。**衰减** 越长，空间越大；**音色** 越低，尾音越暗，就会退到干声后面。

**压住整个混音的峰值。** 在 **主输出** 上添加一个 **Limiter**，把 **上限** 保持在 `-1 dB`。窗口会显示最响的瞬间被压住的频率；如果它一直在工作，那就应该把各音轨调小。

## 乐队协作

- **乐队**：每个人都是 **工程师**（可以修改任何内容）或 **艺术家**（录制自己的声部）。**保护此音轨** 可以防止别人编辑你的声部。
- **会话**：工程师点击 **开始会话**，大家就可以一起现场工作。每个人都能听到任何人演奏的内容。
- **录音条**：每次录音都会保留。用 **使用录音** 挑出最好的一条。
- **评论**：在歌曲的某个位置留下备注，比如“鼓在这里拖拍了”，处理完后点 **解决**。
- **版本**：大改之前先 **保存版本**，如果不喜欢改动后的样子，可以 **恢复**。

不在乐队里的听众也可以播放歌曲、跟随进度和发表评论。

网络断了？继续工作就好。你的更改会被保存，恢复联网后就会发送。

## 在别处工作

当你去聊天或其他频道时，项目会继续播放，录音也会继续录制。这期间，左下角你名字上方会出现一张卡片，显示项目、它是 **正在玩** 还是 **录制**，以及时间。你在项目的语音房间里时也会显示这张卡片。项目在频道列表中的那一行，播放时会显示跳动的柱条，录音时会显示一个红点。

- 点击卡片上的项目名称即可回到项目。
- 在卡片上停止或播放。播放会从你停下的地方继续。
- 如果你在项目中有权停止录音，也可以在卡片上停止。
- 用完了？先停止，再点击 **✕** 关闭卡片。

## 分享成果

**导出** 面板可以：

- 将混音导出为 WAV、FLAC 或 MP3
- 导出 **分轨**（每条音轨单独导出，打包成压缩包）
- **将混音发布到频道**，让大家都能听到
- 将项目保存为 `.dawproject`，以便在其他音乐软件中打开
