在 Parley 中随时按 <kbd>Ctrl</kbd>+<kbd>/</kbd> 就能看到这份列表。在 Mac 上，凡是写着 <kbd>Ctrl</kbd> 的地方都用 <kbd>⌘</kbd>。

## 浏览

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 快速切换器：跳到任意服务器、频道或用户 |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 上一个 / 下一个频道 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 上一个 / 下一个有未读消息的频道 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 上一个 / 下一个服务器 |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | 打开收件箱 |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 已标注消息 |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | 显示或隐藏成员列表 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | 跳转到某个日期 |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | 用户设置 |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | 后退 / 前进（桌面应用） |

## 消息

| 按键 | 作用 |
|---|---|
| <kbd>Enter</kbd> | 发送 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 换行 |
| <kbd>↑</kbd>（在空输入框中） | 编辑你的上一条消息 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | 跳到消息框 |
| <kbd>Esc</kbd> | 取消回复，或将频道标记为已读 |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | 将整个服务器标记为已读 |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | 将选中内容设为粗体 / 斜体 / 下划线 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 删除线 |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | 代码 |

在任何地方直接开始打字，文字就会输入到消息框中。

## 语音

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | 静音或取消静音 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | 关闭或打开声音 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | 保存通话剪辑 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | 开启或关闭主播模式 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | 游戏内浮层（桌面应用） |

## 更改快捷键

打开 **用户设置 → 按键绑定**，可以更改其中任何一个，或添加一个 **按键发言** 按键。桌面应用还可以在你使用其他应用（比如玩游戏）时监听部分快捷键。
