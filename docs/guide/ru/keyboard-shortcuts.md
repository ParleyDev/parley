Нажмите <kbd>Ctrl</kbd>+<kbd>/</kbd> в Parley, чтобы в любой момент увидеть этот список. На Mac используйте <kbd>⌘</kbd> вместо <kbd>Ctrl</kbd>.

## Навигация

| Клавиши | Что делают |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Быстрый переход: к любому серверу, каналу или человеку |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Предыдущий / следующий канал |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Предыдущий / следующий непрочитанный канал |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Предыдущий / следующий сервер |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Открыть входящие |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Закреплённые сообщения |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Показать или скрыть список участников |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Перейти к дате |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Настройки пользователя |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Назад / вперёд (приложение для компьютера) |

## Сообщения

| Клавиши | Что делают |
|---|---|
| <kbd>Enter</kbd> | Отправить |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Новая строка |
| <kbd>↑</kbd> (в пустом поле) | Изменить последнее сообщение |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Перейти к полю сообщения |
| <kbd>Esc</kbd> | Отменить ответ или отметить канал прочитанным |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Отметить весь сервер прочитанным |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Жирный / курсив / подчёркнутый для выделенного |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Зачёркнутый |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Код |

Начните печатать где угодно, и текст попадёт в поле сообщения.

## Голос

| Клавиши | Что делают |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Выключить или включить микрофон |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Выключить или включить звук |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Сохранить клип звонка |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Включить или выключить режим стримера |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Внутриигровой оверлей (приложение для компьютера) |

## Изменение сочетаний

Откройте **Настройки пользователя → Горячие клавиши**, чтобы изменить любое из них или назначить клавишу для режима **Рация**. Приложение для компьютера также может слушать некоторые сочетания, пока вы в другом приложении, например в игре.
