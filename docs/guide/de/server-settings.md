Öffne das Servermenü mit einem Klick auf den Namen des Servers und dann **Servereinstellungen**. Du siehst nur die Seiten, die du ändern darfst. Der Eigentümer sieht alles. Die Einstellungen öffnen sich im selben Fenster wie die Benutzereinstellungen; tippe in das Suchfeld oben in der Liste, um eine Seite zu finden.

![Die Servereinstellungen auf der Seite Serverprofil](shot:server-settings)

## Name, Symbol und Banner

Unter **Serverprofil**:

- **Symbol**: ein quadratisches Bild bis zu 8 MB.
- **Servername**: bis zu 100 Zeichen. **Beschreibung**: bis zu 300.
- **Serverbanner**: das Bild oben in der Kanalliste. Es wird auf 16:9 zugeschnitten; 1920×1080 ist ideal. Animierte GIF, APNG und WebP bleiben animiert.
- **Systemnachrichten-Kanal**: wo Parley neue Mitglieder begrüßt. Auf Wunsch fordert er Mitglieder auf, zur Begrüßung zu winken.
- **Serverregeln**: bis zu 4.000 Zeichen. Hake **Mitglieder müssen die Regeln akzeptieren, bevor sie chatten** an, damit Neulinge zuerst zustimmen.
- **Standard-Benachrichtigungseinstellungen** für neue Mitglieder und ob Mitglieder **Nachrichten planen** dürfen.

Nachdem du ein Bild gewählt hast, ziehst und zoomst du, um den Ausschnitt festzulegen. Um ihn später neu festzulegen, klicke auf **Anpassen**.

Außerdem hier:

- **Serverdesign**: Gib dem Server eigene Farben. Mitglieder können wählen, ob sie sie sehen wollen.
- **Server-Tag**: ein kurzer Tag mit Abzeichen, den Mitglieder neben ihrem Namen tragen können.
- **Statistiken**: wie viele Leute beitreten und bleiben, wie viel los ist und welche Kanäle am beliebtesten sind.

## Leute einladen

Klicke im Servermenü auf **Leute einladen**, um einen Link zum Teilen zu bekommen. Unter **Einladungen** in den Servereinstellungen kannst du eigene Einladungen erstellen:

- **Läuft ab nach**: 30 Minuten bis 30 Tage oder nie.
- **Maximale Anzahl an Verwendungen**: von 1 bis 100 oder unbegrenzt.
- **Vorübergehende Mitgliedschaft gewähren**: Die Leute verlassen den Server automatisch, wenn sie sich abmelden, außer sie haben eine Rolle bekommen.

Jede aktive Einladung wird aufgelistet, mit **Widerrufen**, um sie ungültig zu machen. Öffentliche Server, die unter Entdecken gelistet sind, können außerdem einen eigenen **Wunschlink** haben.

**Zugang**: Um Leute von Hand freizugeben, schalte **Neue Mitglieder prüfen, bevor sie chatten dürfen** ein und schreib ein paar Fragen. Bewerbungen warten, bis du **Genehmigen** oder **Ablehnen** wählst.

## Kanäle und Kategorien

- **Kanal erstellen** steht im Servermenü, oder klicke auf **+** neben einer Kategorie. Die Arten findest du unter [Kanäle](channels#kinds-of-channel).
- Zieh Kanäle und Kategorien, um sie neu anzuordnen.
- Klicke mit der rechten Maustaste auf einen Kanal und wähle **Kanal bearbeiten** für:
  - sein Thema und den **Langsamen Modus**
  - die Einstellungen **Altersbeschränkter Kanal** und **Spoiler**. Ein altersbeschränkter Kanal steht nur Mitgliedern offen, die als mindestens 18 bestätigt sind; alle anderen sehen ihn verschlossen. Schaltest du das für eine Kategorie ein, ist jeder Kanal darin beschränkt. Nur wer selbst bestätigt ist, kann es wieder ausschalten.
  - bei Sprachkanälen: das **Benutzerlimit**, die Video- und Audioqualität und die **Ende-zu-Ende-Verschlüsselung**
  - Forum-**Tags**
  - **Berechtigungen**: siehe [Rollen und Berechtigungen](roles-and-permissions#channel-permissions)

## Emoji, Sticker und Töne

| | Limit | Dateien |
|---|---|---|
| **Emoji** | 100 pro Server | PNG, JPEG, GIF oder WebP unter 512 KB. Namen aus 2 bis 32 Buchstaben, Ziffern oder `_`. |
| **Sticker** | 60 pro Server | Unter 1 MB. 320×320 Pixel funktionieren am besten. |
| **Soundboard** | 48 pro Server | MP3, OGG, WAV, WebM oder M4A unter 512 KB (etwa 5 Sekunden). |

Mitglieder können deine eigenen Emojis auf jedem Server nutzen, auf dem sie sind.

## Neue Mitglieder willkommen heißen

- **Willkommensbildschirm**: eine Begrüßung mit bis zu 5 vorgeschlagenen Kanälen, die erscheint, wenn jemand beitritt.
- **Onboarding**: Fragen an Neulinge („Was führt dich hierher?“). Jede Antwort kann Rollen und Kanäle vergeben, damit die Leute sehen, was für sie relevant ist. Markiere Fragen als **Erforderlich** oder erlaube mehrere Antworten.
- **Regeln**: werden im Serverprofil festgelegt. Mitglieder klicken auf **Ich stimme zu**, bevor sie posten können.

## Communities in deinem Server

Auf einem großen Server gruppierst du Kanäle in [Communities](channels#communities). Jede bekommt eine eigene Seite und eigene Verwalter.

- Erstelle eine mit **+** neben **Communities** in der Kanalliste.
- Öffne ihre Seite und klicke auf **Bearbeiten**. Du kannst festlegen:
  - ihr Icon, ihren Namen und ihre Beschreibung
  - eine Webadresse
  - einen Bereich **Info** und **Links**
  - wer sich um sie kümmert und welche Kanäle dazugehören
- **Titelbild hinzufügen** gibt der Seite ein Banner:
  - Breite Bilder ab 1600 Pixel funktionieren am besten.
  - Klicke auf **Anpassen**, um **Füllen** oder **Einpassen** zu wählen, es am Ausrichtungsraster auszurichten und zu zoomen.
  - Vorschauen zeigen, wie es auf einem Handy, einem Laptop und einem Breitbild aussieht.
- **Community löschen** steht oben in der Bearbeitungsleiste. Damit werden auch die Kanäle der Community und ihre Nachrichten gelöscht.

## Gefunden werden

- **Entdeckung**: Liste den Server unter Entdecken mit einer Kategorie, einer Beschreibung und einem Banner. Ein Admin prüft ihn vorher.
- **Widget**: ein einbettbarer Kasten für deine Website, der zeigt, wer online ist, mit einer Schaltfläche **Beitreten**.
- **Abzeichen**: ein Live-Abzeichen „Join us“ für eine README oder Website.

## Servervorlagen

**Servereinstellungen → Servervorlage** teilt den Aufbau deines Servers (seine Rollen, Kategorien, Kanäle, Berechtigungen und ein paar Einstellungen), damit andere einen ganz ähnlichen Server starten können. Nachrichten, Mitglieder und Emojis werden nie kopiert.

- **Vorlagendatei herunterladen** speichert den Server, wie er gerade ist, als `.json`-Datei. Heb sie als Sicherung deines Aufbaus auf oder schick sie jemandem. Kein Link nötig.
- **Link teilen**: Gib der Vorlage einen Titel und eine Beschreibung und dann **Vorlage generieren**. Der Link bleibt gleich; klicke nach Änderungen an deinem Server auf **Vorlage synchronisieren**, damit der Link den neuen Aufbau liefert. **Vorlage löschen** schaltet den Link ab.

Jeder kann mit **Server hinzufügen → Vorlage verwenden** auf jedem Parley-Server einen Server aus einer Vorlagendatei oder einem Link erstellen. Siehe [Mit einer Vorlage starten](joining-servers#starting-from-a-template).

Wer einen Vorlagenlink öffnet, sieht, was er einrichtet, und kann daraus einen Server erstellen oder ihn als Datei herunterladen.

## Übergeben oder schließen

Diese Optionen stehen ganz unten in der Liste, nur für den Eigentümer:

- **Eigentum übertragen** übergibt den Server an ein anderes Mitglied.
- **Server löschen**: Gib zur Bestätigung den Namen des Servers und dein Passwort ein. Doch anders überlegt? Du hast **7 Tage** Zeit, ihn unter **Benutzereinstellungen → Konto** wiederherzustellen.
