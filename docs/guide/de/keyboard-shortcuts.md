Drück in Parley jederzeit <kbd>Ctrl</kbd>+<kbd>/</kbd>, um diese Liste zu sehen. Auf dem Mac nimmst du <kbd>⌘</kbd> überall dort, wo <kbd>Ctrl</kbd> steht.

## Navigation

| Tasten | Bewirkt |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Schnellwechsler: zu jedem Server, Kanal oder jeder Person springen |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Vorheriger / nächster Kanal |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Vorheriger / nächster ungelesener Kanal |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Vorheriger / nächster Server |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Posteingang öffnen |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Angeheftete Nachrichten |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Mitgliederliste ein- oder ausblenden |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Zu einem Datum springen |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Benutzereinstellungen |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Zurück / vor (Desktop-App) |

## Nachrichten

| Tasten | Bewirkt |
|---|---|
| <kbd>Enter</kbd> | Senden |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Neue Zeile |
| <kbd>↑</kbd> (in einem leeren Feld) | Deine letzte Nachricht bearbeiten |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Zum Nachrichtenfeld springen |
| <kbd>Esc</kbd> | Eine Antwort abbrechen oder den Kanal als gelesen markieren |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Den ganzen Server als gelesen markieren |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Auswahl fett / kursiv / unterstrichen |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Durchgestrichen |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Code |

Fang irgendwo an zu tippen, und deine Wörter landen im Nachrichtenfeld.

## Sprache

| Tasten | Bewirkt |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Stummschalten oder Stummschaltung aufheben |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Ton aus oder wieder an |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Einen Clip des Anrufs speichern |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Streamer-Modus an oder aus |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Overlay im Spiel (Desktop-App) |

## Tastenkürzel ändern

Öffne **Benutzereinstellungen → Tastenkürzel**, um eine davon zu ändern oder eine Taste für **Push-to-Talk** hinzuzufügen. Die Desktop-App kann auf manche Tastenkombinationen auch hören, während du in einer anderen App bist, etwa in einem Spiel.
