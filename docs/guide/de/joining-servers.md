Ein **Server** ist das Zuhause einer Community: ihre Kanäle, ihre Mitglieder und deren Rollen. Du kannst auf so vielen sein, wie du willst.

## Mit einer Einladung beitreten

Jemand schickt dir einen Einladungslink, etwa `app.runparley.com/invite/parley`. Öffne ihn, um Namen, Icon und Mitgliederzahl des Servers zu sehen, und klicke dann auf **Einladung annehmen**.

- **Noch kein Konto?** Die Einladungsseite registriert dich zuerst und bringt dich dann direkt hinein. Manche Server lassen dich vor dem Beitritt schon mal reinlesen.
- **Einladung in einen Chat eingefügt?** Sie erscheint als Karte mit einer Schaltfläche **Beitreten**.
- **Nur den Code bekommen?** Klicke in der Serverliste auf **Server hinzufügen** (+), dann auf **Einem Server beitreten**, und füge den Link oder Code ein.

Wenn eine Einladung nicht funktioniert, ist sie vielleicht abgelaufen oder aufgebraucht, oder der Server nimmt gerade keine neuen Mitglieder auf. Frag nach einer neuen.

## Server in Entdecken finden

Klicke auf den Kompass unten in der Serverliste:

- **Startseite** zeigt empfohlene Server und lässt dich nach Kategorie stöbern.
- **Server** durchsucht alles, was öffentlich gelistet ist.
- **Stages** zeigt laufende Stage-Events, bei denen du reinschauen und zuhören kannst.

Klicke auf einen Server, um dich im Vorschaumodus umzusehen. Du kannst seine öffentlichen Kanäle lesen, bevor du dich festlegst. Wenn du so weit bist, klicke in der Leiste oben auf **Beitreten**.

Manche Server haben einen **Verzeichniskanal**, der andere Server auflistet, denen du beitreten kannst, zum Beispiel die Server der AGs einer Schule.

## Deine ersten Minuten auf einem Server

Server können neue Mitglieder um ein paar Dinge bitten:

- **Onboarding-Fragen.** Wähle, was dich interessiert, und der Server zeigt dir die passenden Kanäle und gibt dir passende Rollen. Meistens kannst du das überspringen.
- **Ein Willkommensbildschirm**, der vorschlägt, wo du anfangen kannst.
- **Regeln zum Akzeptieren.** Bis du auf **Ich stimme zu** klickst, bietet eine Leiste über dem Nachrichtenfeld **Regeln ansehen** an.
- **Sicherheitsprüfungen.** Manche Server wollen eine bestätigte E-Mail-Adresse oder lassen Neulinge ein paar Minuten warten, bevor sie posten dürfen. Das Nachrichtenfeld sagt dir, was nötig ist.

## Einen eigenen Server erstellen

1. Klicke unten in der Serverliste auf **Server hinzufügen** (+).
2. Wähle, wie du starten willst:
   - **Eigenen erstellen**: ein leerer Server.
   - **Vorlage verwenden**: übernimm den Aufbau eines bestehenden Servers, von Parley oder Discord. Siehe [Mit einer Vorlage starten](#starting-from-a-template).
   - **Mit einer Vorlage starten**: Gaming, Freunde, Lerngruppe, Schulclub, Lokale Community oder Künstler & Kreative. Jede bringt sinnvolle Text- und Sprachkanäle mit.
3. Gib ihm einen Namen und ein Icon und klicke dann auf **Erstellen**.

Jetzt lade Leute ein. Klicke auf den Servernamen und dann auf **Leute einladen**. Wie du ihn richtig einrichtest, steht unter [Servereinstellungen](server-settings).

## Mit einer Vorlage beginnen

Eine **Servervorlage** überträgt den Aufbau eines Servers auf einen neuen eigenen Server: seine Rollen, Kategorien, Kanäle, Berechtigungen und ein paar Einstellungen. Nachrichten, Mitglieder und Emojis kommen nie mit.

Klicke auf **Server hinzufügen** (+), dann auf **Vorlage verwenden**, und gib eines davon an:

- **Einen Parley-Vorlagenlink**, etwa `app.runparley.com/template/…`. Er kann von diesem Parley-Server oder von einem anderen stammen.
- **Eine Vorlagendatei** (`.json`): Klicke auf **Datei auswählen** oder zieh die Datei in das Fenster.
- **Einen Discord-Vorlagenlink** (`discord.new/…`) oder seinen Code.

Parley zeigt dir zuerst, was die Vorlage mitbringt: ihre Kanäle und Rollen. Benenne deinen Server, wähle ein Icon und klicke auf **Server erstellen**.

> Tip: Du ziehst mit einer Community von Discord um? Öffne in Discord **Server Settings → Server Template**, klicke auf **Generate Template** und kopiere den Link. Füge ihn hier ein.

Wie du den Aufbau deines eigenen Servers teilst, steht unter [Servervorlagen](server-settings#server-templates).

## Einen Server verlassen

Klicke mit der rechten Maustaste auf den Server und wähle **Server verlassen**. Deine Nachrichten bleiben. Mit einer neuen Einladung kannst du zurückkommen, außer du wurdest gebannt.
