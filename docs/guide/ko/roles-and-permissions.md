**역할**은 *모더레이터*, *아티스트*, *새로 왔어요*처럼 멤버에게 붙이는 이름표예요. 역할마다 그 역할의 멤버가 무엇을 할 수 있는지 정하는 **권한**이 있어요. 역할에는 이름 옆에 표시되는 색과 아이콘도 넣을 수 있어요.

서버의 모든 사람은 자동으로 **@everyone** 역할을 가져요. 이 역할의 권한이 곧 모두가 할 수 있는 일이에요.

![서버 설정의 역할 페이지](shot:roles)

## 역할 만들기

1. **서버 설정 → 역할**을 열고 **역할 만들기**를 클릭하세요.
2. 이름과 색을 정하세요. 원하면:
   - **역할 아이콘**(이모지나 작은 그림)을 넣거나
   - 멤버 목록에서 **온라인 멤버와 역할 멤버를 분리하여 표시**하거나
   - **누구나 이 역할을 @멘션할 수 있도록 허용**하거나
   - **멤버가 이 역할을 직접 선택할 수 있도록 허용**할 수 있어요
3. 이 역할에 필요한 권한을 켜세요.
4. **멤버** 탭에서 사람을 추가하거나, 멤버 목록에서 누군가를 마우스 오른쪽 버튼으로 클릭하고 역할을 고르세요.

**역할 복제하기**는 역할을 복사해요. 비슷한 역할을 만들 때 편리해요.

## 어떤 역할이 우선할까

역할은 순서대로 나열되고, 위에 있는 역할이 아래 역할보다 우선해요. 드래그하거나 **위로 이동**과 **아래로 이동**을 쓰세요.

- 자기의 가장 높은 역할보다 아래에 있는 역할만 관리할 수 있어요.
- 역할마다 색이 다르면 가장 높은 역할의 색이 쓰여요.

**역할로 서버 보기**는 그 역할을 가진 멤버가 보는 화면을 그대로 보여 줘서, 설정을 확인할 수 있어요.

## 권한

권한은 일반, 멤버십, 텍스트, 음성, 스튜디오로 묶여 있어요. 가장 중요한 몇 가지:

| 권한 | 할 수 있는 일… |
|---|---|
| **관리자** | 모든 것을 할 수 있고, 모든 채널 제한을 건너뛰어요. 꼭 필요한 사람에게만 주세요. |
| **서버 관리하기** | 서버 이름, 아이콘, 설정을 바꿔요. |
| **역할 관리하기** | 자기 역할보다 아래의 역할을 만들고 부여해요. |
| **채널 관리하기** | 채널을 만들고, 편집하고, 삭제해요. |
| **멤버 추방하기 / 멤버 차단하기 / 멤버 타임아웃하기** | 사람들을 관리해요. [관리](moderation)를 참고하세요. |
| **메시지 관리하기** | 누구의 메시지든 삭제하고 고정해요. |
| **@everyone 멘션하기** | 서버 전체를 호출해요. |
| **초대 만들기** | 새로운 사람을 초대해요. |
| **표현 관리하기** | 이모지, 스티커, 소리를 추가해요. |
| **이벤트 관리하기** | 이벤트를 예약해요. |
| **감사 로그 보기** | 누가 무엇을 바꿨는지 봐요. |

> Tip: 처음에는 **@everyone**이 읽고 채팅할 수 있게 두세요. 그다음 추방, 타임아웃, 메시지 관리 권한이 있는 *모더레이터* 역할을 추가하세요. 관리자 권한이 필요한 사람은 많지 않아요.

## 채널 권한

채널을 비공개로 만들거나 한 채널에서 할 수 있는 일을 바꾸려면:

1. 채널을 마우스 오른쪽 버튼으로 클릭하고 **채널 편집하기**를 고른 뒤 **권한**을 누르세요.
2. **비공개 채널**을 켜면 내가 추가한 역할과 사람 외에는 아무도 볼 수 없어요.
3. 또는 **역할 또는 멤버 추가**를 쓰고 권한마다 **허용**(✓), **거부**(✗), **상속**(/, 서버 전체 설정)을 정하세요.

카테고리에도 권한이 있어요. 카테고리와 같은 채널에는 **동기화됨**이라고 표시돼요. 채널을 바꾼 뒤 **지금 동기화**를 누르면 다시 카테고리와 같아져요.

## 멤버 목록

**서버 설정 → 멤버**에 모든 사람이 나와요. 검색하고, 역할로 거르고, 각자 어떻게 들어왔는지 보고, 역할을 주거나 빼세요. 여러 사람을 한 번에 골라 추방하거나 차단할 수도 있어요.

## 연동 역할

연동 역할은 Twitch 구독자처럼 계정을 연결한 사람에게 자동으로 주어지는 역할이에요. **연동**에서 설정하세요.
