## 한눈에 보는 창 구성

왼쪽부터 오른쪽으로:

1. **서버 목록.** 맨 위에는 개인 대화와 친구가 있는 **개인 메시지**가 있어요. 그 아래에 내 서버들이 있고, 맨 아래에는 **서버 추가하기**(+)와 **탐색**(나침반)이 있어요.
2. 지금 있는 서버의 **채널 목록.** 맨 위에 서버 이름과 배너가 있고, 이름을 클릭하면 서버 메뉴가 열려요. 맨 아래에는 내 패널이 있어요.
3. **대화.** 메시지가 표시되고, 그 아래에 메시지 입력창이 있어요. 맨 위 막대에는 채널 이름과 스레드, 고정 메시지, 멤버 목록, 검색, 받은 편지함 버튼이 있어요.
4. **멤버 목록.** 채널을 볼 수 있는 모든 사람이 역할별로, 그다음 온라인과 오프라인으로 묶여 있어요. 누구든 클릭하면 프로필을 볼 수 있어요.

> Tip: 공간이 부족한가요? 맨 위 막대의 사람 버튼이나 <kbd>Ctrl</kbd>+<kbd>U</kbd>로 멤버 목록을 숨기세요.

## 내 패널

왼쪽 아래 구석이 바로 나예요. 마이크와 헤드폰 버튼으로 마이크 음소거와 헤드셋 음소거를 해요. 각 버튼 옆의 작은 화살표로 마이크나 스피커를 골라요. 톱니바퀴를 누르면 **사용자 설정**이 열려요.

내 사진을 클릭하면:

- **상태** 설정: 온라인, 자리 비움, 방해 금지, 오프라인 표시를 계속 또는 잠시 동안
- **사용자 지정 상태 설정하기**: 모두에게 보이는 이모지와 짧은 한 줄
- **프로필 편집하기**
- 계정이 여러 개라면 **계정 전환하기**

통화 중에는 내 패널 바로 위에 통화 컨트롤이 있는 **음성 연결됨** 카드가 표시돼요. [음성 및 영상](voice-and-video)을 참고하세요.

## 서버 폴더

서버 목록이 길다면 폴더로 정리하면 편해요.

- 서버 하나를 다른 서버 위로 끌어다 놓으면 폴더가 만들어져요.
- 서버를 더 끌어 넣거나 다시 끌어내세요.
- 폴더를 클릭하면 열리고 닫혀요. 닫힌 폴더에는 안에 있는 서버가 작게 미리 보여요.
- 폴더를 마우스 오른쪽 버튼으로 클릭하고 **폴더 설정**을 고르면 이름을 짓거나, 색을 정하거나, 폴더를 없앨 수 있어요.

서버를 마우스 오른쪽 버튼으로 클릭해서 **폴더에 추가하기**, **위로 이동**, **아래로 이동**을 쓸 수도 있어요. 배치는 계정에 저장되므로 모든 기기에서 그대로 따라와요.

## 마우스 오른쪽 버튼 메뉴

거의 모든 것에 메뉴가 있어요. 마우스 오른쪽 버튼으로 클릭하거나 휴대폰에서는 길게 누르세요.

- **서버:** 읽음으로 표시하기, 친구 초대하기, 알림 설정, 서버 설정, 서버 나가기.
- **채널:** 읽음으로 표시하기, **채널 고정하기**(목록 맨 위에 고정), 친구 초대하기, 링크 복사하기, 음소거 및 알림 설정.
- **카테고리:** 접거나 펼치기, 또는 전체를 한 번에.
- **사람:** 프로필, 메시지, 통화, 친구 추가하기, 서버에 초대하기, 차단하기, 사용자 신고하기.
- **메시지:** [메시지](messages#the-message-menu)를 참고하세요.

## 빠른 전환기

<kbd>Ctrl</kbd>+<kbd>K</kbd>(Mac에서는 <kbd>⌘</kbd>+<kbd>K</kbd>)를 누르고 서버, 채널, 사람의 이름을 입력하기 시작하세요. <kbd>Enter</kbd>를 누르면 그곳으로 이동해요. 입력하기 전에는 읽지 않은 곳과 최근에 간 곳이 표시돼요.

## 메시지 검색하기

오른쪽 위 검색창에 입력하고 <kbd>Enter</kbd>를 누르세요. 결과는 채팅 옆 패널에 열려요. 결과에서 **이동**을 클릭하면 대화 속에서 그 메시지를 볼 수 있어요.

- 검색할 곳을 고르세요: **이 채널**, **이 서버** 또는 **모든 곳**(DM 포함).
- **관련도순**, **최신순**, **오래된순**으로 정렬하세요.
- 필터로 범위를 좁히세요. 입력하는 동안 검색창이 필터를 제안해요.

| 필터 | 찾는 메시지… |
|---|---|
| `from:` | 특정 사람이 보낸 메시지 |
| `mentions:` | 특정 사람을 멘션한 메시지 |
| `in:` | 특정 채널의 메시지 |
| `has:` | `link`, `embed`, `image`, `video`, `file`, `sticker`, `poll`, `sound`가 있는 메시지 |
| `before:` `during:` `after:` | 특정 날짜 전후의 메시지 |
| `pinned:true` | 고정된 메시지 |

특정 날짜로 돌아가려면 맨 위 막대의 달력 버튼이나 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd>를 쓰세요. 멀리 거슬러 올라갔다면 **현재로 이동**을 눌러 최신 메시지로 돌아오세요.

검색한 단어는 각 결과에 표시됩니다. 검색을 실행할 수 없으면 패널이 이를 알리고 **다시 시도**을(를) 제공합니다. 휴대폰에서는 결과가 화면 전체에 표시됩니다.

## 휴대폰에서

휴대폰의 Parley는 한 번에 하나씩 보여 줘요.

- 오른쪽으로 밀면 서버와 채널 목록이 나와요.
- 왼쪽으로 밀면 멤버 목록이 나와요.
- 모든 화면 맨 위에 뒤로 가기 버튼이 있어요.
- 컴퓨터에서 마우스 오른쪽 버튼으로 여는 메뉴는 길게 눌러서 열어요.

## 시작하기 체크리스트

새 계정에는 짧은 체크리스트가 보여요: 프로필 사진 추가, 친구 추가, 서버 참여 또는 만들기, 사용자 지정 상태 설정, 그리고 패스키 추가나 2단계 인증 켜기(둘 중 하나만 해도 체크돼요). 각 항목을 누르면 해당 위치로 이동해요. 원할 때 언제든 닫을 수 있어요.

## 도움 받기

이 가이드는 언제나 클릭 한 번이면 열려요.

- 내 사진 아래 메뉴와 사용자 설정 맨 아래의 **도움말 및 가이드**를 누르면 가이드 첫 페이지가 열려요.
- 사용자 설정, 서버 설정, 채널 설정의 모든 페이지 맨 위에 **도움말** 버튼이 있어요. 그 페이지에 해당하는 가이드 부분을 열어 줘요.
- 단축키 안내(<kbd>Ctrl</kbd>+<kbd>/</kbd>)에서 [단축키](keyboard-shortcuts)로 연결돼요.
