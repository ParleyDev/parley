## 메시지 보내기

아래쪽 입력창에 입력하고 <kbd>Enter</kbd>를 누르세요. 보내지 않고 줄을 바꾸려면 <kbd>Shift</kbd>+<kbd>Enter</kbd>를 누르세요.

- 오타가 났나요? 빈 입력창에서 <kbd>↑</kbd>를 누르면 마지막 메시지를 수정할 수 있어요.
- 쓰다 만 메시지는 채널마다 보관돼요. 나중에 돌아와도 임시 저장한 글이 그대로 있어요.
- 메시지는 최대 2,000자까지 쓸 수 있어요. 더 긴 글은 클릭 한 번으로 파일로 보낼 수 있어요.

## 서식

텍스트를 선택하면 작은 도구 모음이 나와요: **굵게**, *기울임꼴*, 밑줄, 취소선, 코드, 스포일러. 직접 서식을 입력해도 돼요.

| 이렇게 입력하면 | 이렇게 돼요 |
|---|---|
| `**bold**` | **굵게** |
| `*italic*` | *기울임꼴* |
| `__underline__` | 밑줄 친 텍스트 |
| `~~strike~~` | 취소선 텍스트 |
| `` `code` `` | `code` |
| `\|\|spoiler\|\|` | 클릭하기 전까지 가려진 텍스트 |
| `# Big heading` (`##`, `###`도 가능) | 제목 |
| `-# small print` | 작은 회색 글씨 |
| `> quote` | 인용 (`>>>`는 그 뒤 전체를 인용) |
| `- item` 또는 `1. item` | 목록 |
| `[text](https://…)` | 원하는 텍스트를 붙인 링크 |

코드 블록을 넣으려면 앞뒤 줄에 백틱 세 개를 쓰세요. 첫 백틱 세 개 뒤에 언어 이름(`` ```python ``)을 붙이면 색이 입혀져요. 코드 블록에는 **복사하기** 버튼이 생겨요.

단축키도 쓸 수 있어요: <kbd>Ctrl</kbd>+<kbd>B</kbd> 굵게, <kbd>Ctrl</kbd>+<kbd>I</kbd> 기울임꼴, <kbd>Ctrl</kbd>+<kbd>U</kbd> 밑줄, <kbd>Ctrl</kbd>+<kbd>E</kbd> 코드.

## 멘션

- `@`와 이름을 입력하면 그 사람을 멘션해요. 상대는 알림을 받고, 메시지가 강조되어 보여요.
- `@`로 역할도 찾을 수 있고, `@everyone`(채널의 모든 사람)과 `@here`(온라인인 모든 사람)도 있어요. 누가 이걸 쓸 수 있는지는 서버가 정해요.
- `#`을 입력하면 채널 링크를 넣어요.

<kbd>↑</kbd>와 <kbd>↓</kbd>로 제안 중에서 고르고, <kbd>Enter</kbd>나 <kbd>Tab</kbd>으로 선택하세요.

## 이모지, 스티커, GIF

메시지 입력창 오른쪽의 버튼 세 개로 **GIF**, **스티커**, **이모지** 선택 창을 열어요.

- **이모지:** 검색, 자주 쓰는 이모지, 모든 서버의 커스텀 이모지, 피부색 선택. 또는 `:tada`처럼 `:`와 이름을 입력하고 목록에서 고르세요.
- Parley는 모든 기기에서 이모지를 같은 스타일로 그려서, 컴퓨터 자체 이모지가 오래된 곳에서도 국기를 포함해 모두가 똑같이 보여요.
- 내가 속한 어떤 서버의 **커스텀 이모지**든 글을 쓸 수 있는 곳 어디서나 쓸 수 있어요. 메시지 속 이모지를 클릭하면 어느 서버 것인지 볼 수 있어요.
- **스티커**는 내 서버들에서 가져와요.
- **GIF:** 검색, 인기, 카테고리. GIF에 마우스를 올리고 별을 클릭하면 **즐겨찾기**에 보관돼요.

## 반응

메시지에 마우스를 올리고 가장 많이 쓰는 이모지 중에서 고르거나, **반응 추가하기**를 클릭해 전체 선택 창을 여세요. **슈퍼 반응 추가하기**는 움직이는 반응을 달아요.

메시지 아래의 반응을 클릭하면 내 반응이 더해지고, 다시 클릭하면 취소돼요. 반응에 마우스를 올리면 누가 반응했는지 보이고, 메시지 메뉴의 **반응 보기**로도 볼 수 있어요.

## 답장, 수정, 삭제

- **답장하기**는 원래 메시지를 내 메시지 위에 인용하고 작성자에게 알려요. 취소하려면 <kbd>Esc</kbd>를 누르세요.
- **메시지 수정하기**로 쓴 내용을 바꿔요. 수정한 메시지에는 **(수정됨)**이 붙어요. 그걸 클릭하면 이전 버전을 볼 수 있어요.
- **메시지 삭제하기**는 모든 사람에게서 메시지를 지워요.

답장 위의 인용 줄을 클릭하면 답장한 원래 메시지를 볼 수 있습니다. 아래 바의 **뒤로** 또는 <kbd>Esc</kbd>로 원래 있던 곳으로 돌아갑니다.

## 메시지 메뉴

메시지를 마우스 오른쪽 버튼으로 클릭하거나, **⋯** 버튼을 클릭하거나, 휴대폰에서 길게 누르세요. 이런 항목이 있어요.

- **답장하기**, **전달하기**, **스레드 만들기**
- **텍스트 복사하기**와 **메시지 링크 복사하기**
- **메시지 고정하기**. 고정된 메시지는 맨 위 막대의 고정 버튼(<kbd>Ctrl</kbd>+<kbd>P</kbd>) 아래에 모여 있어요.
- **메시지 북마크하기**: [받은 편지함](notifications#your-inbox)에 저장해서 나중에 보기
- **알림 받기**: 20분, 1시간, 3시간 후, 내일 또는 다음 주에
- **읽지 않음으로 표시하기**: 나중에 다시 보기
- 서버에서 제공한다면 **번역**, 그리고 소리 내어 읽어 주는 **메시지 읽어주기**
- 링크 미리 보기를 숨기는 **임베드 삭제**
- 규칙을 어기는 내용에는 **메시지 신고하기**

## 파일, 사진, 동영상

**+**를 클릭하고 **파일 업로드**를 누르거나, 파일을 채팅으로 끌어오거나, 붙여 넣으세요.

- 메시지 하나에 파일 10개까지, 보통 파일당 25 MB까지예요. 서버 호스트가 더 허용할 수도 있어요.
- 보내기 전에 **스포일러로 표시**하거나 **대체 텍스트 추가**를 할 수 있어요. 대체 텍스트는 화면 낭독기를 쓰는 사람을 위한 설명이에요.
- 사진은 클릭하면 원래 크기로 열려요. 동영상과 오디오는 채팅 안에서 바로 재생돼요.
- 음악 파일에는 파일 자체의 태그에서 가져온 곡 제목, 아티스트, 앨범, 커버 아트가 표시돼요.
- 파일에서 **링크 복사하기**를 누르면 하루나 이틀 동안만 쓸 수 있는 링크가 나와요. 그 뒤에는 열리지 않아서, 비공개 대화의 파일이 링크를 가진 누구에게나 계속 열려 있지 않아요. 파일을 더 오래 공유하려면 메시지를 전달하거나 파일을 다시 보내세요.

## 음성 메시지

**+**를 클릭하고 **음성 메시지 녹음하기**를 누르세요. 말한 뒤 보내거나 버리면 돼요. 듣는 사람은 1.5배나 2배로 빨리 들을 수 있어요. 서버에서 받아쓰기를 켰다면 글로 읽을 수도 있어요.

## 투표

**+**를 클릭하고 **투표 만들기**를 누르세요.

1. 질문과 답변 2~10개를 쓰세요. 답변마다 이모지를 붙일 수 있어요.
2. 답변을 여러 개 고를 수 있게 할지 정하세요.
3. 1시간부터 1주일까지, 또는 기한 없이 투표 기간을 정하세요.
4. **투표 올리기**를 클릭하세요.

결과는 실시간으로 업데이트돼요. 투표를 만든 사람은 일찍 마감할 수 있어요.

## 메시지 예약하기

메시지를 쓴 뒤 **보내기** 버튼을 마우스 오른쪽 버튼으로 클릭하고(휴대폰에서는 길게 누르기) **메시지 예약하기**를 고르세요. **내일 아침** 같은 시간을 고르거나 **사용자 지정**을 선택하세요.

예약 메시지는 30개까지 둘 수 있어요. [받은 편지함](notifications#your-inbox)의 **예약됨**에서 찾을 수 있고, 거기서 **지금 보내기**, 수정, 삭제를 할 수 있어요.

## 전달하기

**전달하기**는 메시지 사본을 다른 채널이나 사람에게 보내요. *전달됨* 표시가 붙고, 원래 메시지가 삭제되어도 남아 있어요.

## 슬래시 명령어

입력창 맨 앞에 `/`를 입력하면 쓸 수 있는 명령어가 보여요.

| 명령어 | 하는 일 |
|---|---|
| `/shrug` `/tableflip` `/unflip` `/lenny` | 메시지에 표정을 붙여요 |
| `/me` | 메시지를 행동처럼 기울임꼴로 보내요 |
| `/spoiler` | 메시지 전체를 클릭하기 전까지 가려요 |
| `/tts` | 채널을 보고 있는 모두에게 메시지를 소리 내어 읽어 줘요 |
| `/nick` | 이 서버에서 내 별명을 바꿔요 |

서버의 앱과 봇이 자기 명령어를 추가하기도 해요. [앱과 봇](apps-and-bots)을 참고하세요.

## 요약

채널이 바쁜가요? 맨 위 막대의 **요약** 버튼을 누르면 최근 이틀 정도의 내용을 빠르게 요약해 줘요. 요약은 자동으로 작성되므로, 믿기 전에 원래 메시지를 확인하세요. 서버에서 이 기능을 끌 수 있어요.
