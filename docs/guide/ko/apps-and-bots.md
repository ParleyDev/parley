**앱**은 Parley에 기능을 더해요. **봇**은 멤버처럼 서버에 들어오는 앱이에요. 사람들을 환영하고, 게임을 진행하고, 음악을 틀고, 소식을 올릴 수 있어요.

## 앱 찾기

탐색(**앱 디렉터리 둘러보기**)이나 **사용자 설정 → 승인된 앱**에서 **앱 디렉터리**를 여세요. 검색하거나 카테고리별로 둘러보세요. **인증됨** 배지는 Parley가 만든 사람을 확인했다는 뜻이에요.

## 서버에 봇 추가하기

1. 앱에서 **서버에 추가**를 클릭하거나, 만든 사람이 준 초대 링크를 여세요.
2. **서버 관리하기** 권한이 있는 서버를 고르세요.
3. 요청하는 권한을 확인하세요. 필요 없는 권한은 체크를 해제하세요.
4. **승인하기**를 클릭하세요.

봇은 자기만의 역할을 받아요. **서버 설정 → 역할**에서 권한을 바꿀 수 있어요. 봇을 내보내려면 **서버 설정 → 연동**을 쓰거나 다른 멤버처럼 추방하세요.

## 나만의 앱

어떤 앱은 **내 앱에 추가**로 내 계정에 추가할 수 있어요. 그러면 어떤 서버나 DM에서든 쓸 수 있어요. 메시지나 사람을 마우스 오른쪽 버튼으로 클릭했을 때 **앱** 아래에도 나타나요.

## 명령어 쓰기

메시지 입력창 맨 앞에 `/`를 입력하세요. Parley 자체 명령어가 먼저 나오고, 그다음 그곳에서 쓸 수 있는 모든 앱의 명령어가 나와요. 하나를 고르고, 옵션을 채우고, <kbd>Enter</kbd>를 누르세요. 어떤 앱은 양식을 열거나 나에게만 답해요.

## AI 어시스턴트

Claude, ChatGPT, Cursor 같은 AI 어시스턴트가 나 대신 메시지를 읽고 보내게 할 수 있어요. "내가 놓친 거 있어?"나 "Sam에게 나 좀 늦는다고 답장해 줘" 같은 걸 물어보세요.

1. **사용자 설정 → 승인된 앱**을 열고 **AI 어시스턴트 (MCP)** 아래의 주소를 복사하세요.
2. 어시스턴트에서 이 주소를 사용자 지정 커넥터로 추가하세요(*원격 MCP 서버*라고 부르기도 해요).
3. Parley가 어시스턴트에게 무엇을 허용할지 묻는 페이지를 열어요: **읽음**, **알림**, **메시지 보내기**, **서버 관리**. 필요한 것만 고르고 승인하세요.

> Heads up: 어시스턴트가 보내는 모든 것은 내 이름으로 표시돼요. **서버 관리**가 있으면 메시지를 지우거나 사람을 내보낼 수도 있으니, 정말 그럴 생각일 때만 허용하세요.

멈추려면 **승인된 앱**에서 어시스턴트 옆의 **연결 끊기**를 클릭하세요.

## 관리자용 도구

프로필 꾸미기 아이템을 만드는 Profile Studio처럼 내 인스턴스에서 작동하는 도구도 같은 방식으로 로그인해요. 도구에서 로그인하면 Parley가 **꾸미기 아이템 관리**를 허용할지 묻는 페이지를 열어요. 인스턴스에 꾸미기 아이템을 추가하고 기존 아이템을 바꿀 수 있는 권한이에요. 내 계정이 인스턴스를 관리할 수 있을 때만 작동하고, 도구는 내 비밀번호를 절대 볼 수 없어요.

> Heads up: 도구가 추가하거나 바꾼 것은 모두에게 한꺼번에 보여요. 믿을 수 있는 도구만 허용하세요.

멈추려면 **승인된 앱**에서 도구 옆의 **연결 끊기**를 클릭하세요.

## 직접 만들기

봇을 만들어 보고 싶나요? **사용자 설정 → 애플리케이션**에서 앱을 만들고 [개발자 문서](https://app.runparley.com/developers)를 읽어 보세요.
