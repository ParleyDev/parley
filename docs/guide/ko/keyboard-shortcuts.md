Parley에서 <kbd>Ctrl</kbd>+<kbd>/</kbd>를 누르면 언제든 이 목록을 볼 수 있어요. Mac에서는 <kbd>Ctrl</kbd> 대신 <kbd>⌘</kbd>를 쓰세요.

## 이동하기

| 키 | 하는 일 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 빠른 전환기: 어떤 서버, 채널, 사람에게든 바로 이동 |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 이전 / 다음 채널 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 이전 / 다음 읽지 않은 채널 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 이전 / 다음 서버 |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | 받은 편지함 열기 |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 고정된 메시지 |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | 멤버 목록 보이기 또는 숨기기 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | 날짜로 이동 |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | 사용자 설정 |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | 뒤로 / 앞으로 (데스크톱 앱) |

## 메시지

| 키 | 하는 일 |
|---|---|
| <kbd>Enter</kbd> | 보내기 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 줄 바꾸기 |
| <kbd>↑</kbd> (빈 입력창에서) | 마지막 메시지 수정하기 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | 메시지 입력창으로 이동 |
| <kbd>Esc</kbd> | 답장 취소 또는 채널을 읽음으로 표시 |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | 서버 전체를 읽음으로 표시 |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | 선택한 텍스트 굵게 / 기울임꼴 / 밑줄 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 취소선 |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | 코드 |

어디서든 입력을 시작하면 글자가 메시지 입력창에 들어가요.

## 음성

| 키 | 하는 일 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | 마이크 음소거 또는 해제 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | 헤드셋 음소거 또는 해제 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | 통화 클립 저장 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | 스트리머 모드 켜기 또는 끄기 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | 게임 내 오버레이 (데스크톱 앱) |

## 단축키 바꾸기

**사용자 설정 → 단축키**를 열어 이 중 무엇이든 바꾸거나 **눌러서 말하기** 키를 추가하세요. 데스크톱 앱은 게임처럼 다른 앱을 쓰는 동안에도 일부 단축키를 인식할 수 있어요.
