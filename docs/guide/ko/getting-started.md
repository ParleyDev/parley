Parley는 친구, 커뮤니티와 이야기하는 곳이에요. 텍스트 채팅, 음성 및 영상 통화, 라이브 스테이지, 음악 스튜디오가 있어요. 모든 기능은 누구에게나 무료예요.

## 계정 없이 써 보기

먼저 둘러보고 싶나요? [app.runparley.com/try](https://app.runparley.com/try)를 열거나 로그인 페이지에서 **계정 없이 써 보기**를 클릭하세요. 게스트 이용권으로 데모 서버에 바로 들어가요.

게스트 계정은 나간 지 한 시간 후에 삭제돼요. 계속 쓰려면 배너에서 **가입해서 유지하기**를 클릭하세요. 메시지, 프로필, 서버가 그대로 유지돼요.

## 계정 만들기

1. [app.runparley.com/register](https://app.runparley.com/register)로 가세요.
2. 이메일을 입력하고 **사용자명**을 정하세요. 문자, 숫자, `_`, `.`로 2~32자예요. 다른 사람이 이 이름으로 나를 찾을 수 있어요.
3. 원하면 **표시 이름**을 추가하세요. 다른 사람에게 보이는 이름으로, 띄어쓰기와 대문자를 쓸 수 있어요.
4. 8자 이상의 비밀번호를 정하고 **계속하기**를 클릭하세요.

Parley가 주소 인증 링크를 이메일로 보내요. 링크를 클릭하기 전에도 채팅은 할 수 있지만, 서버를 만들거나 탐색을 쓸 수는 없어요. 이메일이 오지 않았다면 앱 맨 위 배너에서 **다시 보내기**를 누르세요.

## 로그인하기

다음 중 어떤 방법으로든 로그인할 수 있어요.

- **이메일 또는 사용자명과 비밀번호.**
- **패스키**: 지문, 얼굴 또는 기기 PIN으로, 비밀번호를 입력할 필요가 없어요. **사용자 설정 → 계정**에서 추가하세요.
- **QR 코드.** 컴퓨터의 로그인 페이지에 코드가 표시돼요. 이미 로그인한 휴대폰으로 스캔하고 **네, 로그인할게요**로 확인하세요.

> Heads up: 내 화면에 보이는 Parley 로그인 코드만 스캔하세요. 다른 사람이 보낸 코드는 절대 스캔하지 마세요. 그러면 *그 사람*이 내 계정으로 로그인하게 돼요.

[2단계 인증](settings#account)을 켰다면 인증 앱의 6자리 코드, 백업 코드 또는 보안 키도 요청해요.

**비밀번호를 잊으셨나요?** 로그인 페이지에서 **비밀번호를 잊으셨나요?**를 클릭하면 새 비밀번호를 정하는 링크를 이메일로 보내 드려요.

**계정이 여러 개인가요?** 내 사진을 클릭한 뒤 **계정 전환하기**를 눌러 다른 계정을 추가하고 오갈 수 있어요.

## 내 기기에 Parley 설치하기

| 어디서 | 방법 |
|---|---|
| **웹 브라우저** | [app.runparley.com](https://app.runparley.com)으로 가세요. 설치할 것이 없어요. 사용자 설정의 **앱 설치**로 홈 화면이나 Dock에 추가할 수도 있어요. |
| **Windows, macOS, Linux** | [runparley.com](https://runparley.com/#download)에서 데스크톱 앱을 다운로드하세요. 백그라운드에서 실행되고, 게임 중에도 눌러서 말하기가 작동하며, 게임 내 오버레이가 있어요. |
| **Android** | 푸시 알림을 받고 화면이 꺼져도 통화를 이어가려면 [runparley.com](https://runparley.com/#download)에서 앱을 설치하세요. |
| **iPhone 및 iPad** | Safari에서 [app.runparley.com](https://app.runparley.com)을 쓰고, 알림을 받으려면 **홈 화면에 추가**하세요. |

데스크톱 앱은 스스로 업데이트해요. 업데이트가 준비되면 초록색 화살표가 나타나요. **다시 시작해서 업데이트**를 클릭하세요.

> Note: Parley는 오픈 소스라서 누구나 자신의 Parley 서버를 운영할 수 있어요. 앱은 어느 서버에 연결할지 물어봐요. **app.runparley.com**을 고르거나 커뮤니티의 주소를 입력하세요. 나중에 사용자 설정의 **서버 전환**으로 바꿀 수 있어요.

## 잠시 쉬거나 떠나기

**사용자 설정 → 계정**의 **계정 삭제** 아래에서:

- **계정 비활성화하기**는 모든 곳에서 로그아웃하고 계정을 숨겨요. 아무것도 삭제되지 않아요. 다시 켜고 싶을 때 언제든 로그인하면 돼요.
- **계정 삭제하기**는 계정을 영구히 삭제해요. 삭제하기 전에 내가 소유한 서버와 앱을 넘기거나 삭제하라는 안내가 나와요. 그다음 비밀번호로 확인하세요.

삭제한 뒤 **14일** 동안은 마음을 바꿀 수 있어요. 로그인해서 **내 계정 복원**을 고르기만 하면 돼요. 그 후에는 개인 정보가 지워져요. 예전 메시지는 그대로 남지만 *삭제된 사용자*가 보낸 것으로 표시돼요.

앱을 열지 않고 [app.runparley.com/delete-account](https://app.runparley.com/delete-account)에서도 계정을 삭제할 수 있어요.
