Bu listeyi istediğin zaman görmek için Parley'de <kbd>Ctrl</kbd>+<kbd>/</kbd> tuşlarına bas. Mac'te <kbd>Ctrl</kbd> yazan her yerde <kbd>⌘</kbd> kullan.

## Gezinmek

| Tuşlar | Ne yapar |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Hızlı geçiş: herhangi bir sunucuya, kanala veya kişiye atla |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Önceki / sonraki kanal |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Önceki / sonraki okunmamış kanal |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Önceki / sonraki sunucu |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Gelen kutunu aç |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Sabitlenmiş mesajlar |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Üye listesini göster veya gizle |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Bir tarihe atla |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Kullanıcı Ayarları |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Geri / ileri (masaüstü uygulaması) |

## Mesajlar

| Tuşlar | Ne yapar |
|---|---|
| <kbd>Enter</kbd> | Gönder |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Yeni satır |
| <kbd>↑</kbd> (boş kutuda) | Son mesajını düzenle |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Mesaj kutusuna git |
| <kbd>Esc</kbd> | Yanıtı iptal et ya da kanalı okundu olarak işaretle |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Tüm sunucuyu okundu olarak işaretle |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Seçimi kalın / italik / altı çizili yap |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Üstü çizili |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Kod |

Herhangi bir yerde yazmaya başla, yazdıkların mesaj kutusuna gider.

## Ses

| Tuşlar | Ne yapar |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Sustur veya susturmayı kaldır |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Sağırlaştır veya sağırlaştırmayı kaldır |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Aramadan bir klip kaydet |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Yayıncı Modu'nu aç veya kapat |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Oyun içi katman (masaüstü uygulaması) |

## Kısayolları değiştirmek

Bunlardan herhangi birini değiştirmek ya da bir **Bas Konuş** tuşu eklemek için **Kullanıcı Ayarları → Tuş Atamaları**'nı aç. Masaüstü uygulaması, sen oyun gibi başka bir uygulamadayken bazı kısayolları da dinleyebilir.
