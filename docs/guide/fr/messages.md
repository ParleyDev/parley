## Envoyer un message

Tape dans la zone en bas et appuie sur <kbd>Enter</kbd>. Pour aller à la ligne sans envoyer, appuie sur <kbd>Shift</kbd>+<kbd>Enter</kbd>.

- Une faute de frappe ? Appuie sur <kbd>↑</kbd> dans une zone vide pour modifier ton dernier message.
- Les messages à moitié écrits sont gardés pour chaque salon. Reviens plus tard, ton brouillon est toujours là.
- Un message peut faire jusqu'à 2 000 caractères. Au-delà, tu peux l'envoyer en fichier en un clic.

## Mise en forme

Sélectionne du texte pour faire apparaître une petite barre d'outils : **gras**, *italique*, souligné, barré, code et spoiler. Ou tape la mise en forme toi-même :

| Tape ceci | Pour obtenir |
|---|---|
| `**bold**` | **gras** |
| `*italic*` | *italique* |
| `__underline__` | du texte souligné |
| `~~strike~~` | du texte barré |
| `` `code` `` | `code` |
| `\|\|spoiler\|\|` | du texte masqué jusqu'au clic |
| `# Big heading` (aussi `##`, `###`) | un titre |
| `-# small print` | du petit texte gris |
| `> quote` | une citation (`>>>` cite tout ce qui suit) |
| `- item` ou `1. item` | une liste |
| `[text](https://…)` | un lien avec ton propre texte |

Pour un bloc de code, mets trois accents graves sur la ligne d'avant et sur celle d'après. Ajoute un nom de langage après les trois premiers (`` ```python ``) pour la coloration. Les blocs de code ont un bouton **Copier**.

Les raccourcis clavier marchent aussi : <kbd>Ctrl</kbd>+<kbd>B</kbd> gras, <kbd>Ctrl</kbd>+<kbd>I</kbd> italique, <kbd>Ctrl</kbd>+<kbd>U</kbd> souligné, <kbd>Ctrl</kbd>+<kbd>E</kbd> code.

## Mentions

- Tape `@` suivi d'un nom pour mentionner quelqu'un. La personne reçoit une notification et le message est mis en évidence pour elle.
- `@` trouve aussi les rôles, ainsi que `@everyone` (tout le monde dans le salon) et `@here` (tout le monde en ligne). Les serveurs décident qui peut les utiliser.
- Tape `#` pour faire un lien vers un salon.

Utilise <kbd>↑</kbd> et <kbd>↓</kbd> pour parcourir les suggestions, puis <kbd>Enter</kbd> ou <kbd>Tab</kbd> pour choisir.

## Émojis, autocollants et GIF

Les trois boutons à droite de la zone de saisie ouvrent les sélecteurs **GIF**, **Autocollant** et **Émoji**.

- **Émojis :** recherche, tes plus utilisés, les émojis personnalisés de chaque serveur et un choix de couleur de peau. Ou tape `:` suivi d'un nom, comme `:tada`, et choisis dans la liste.
- Parley dessine les émojis dans un seul style sur tous les appareils, pour que tout le monde voie la même chose, drapeaux compris, même là où les émojis de l'ordinateur sont dépassés.
- Les **émojis personnalisés** de tous tes serveurs fonctionnent partout où tu peux publier. Clique sur l'un d'eux dans un message pour voir d'où il vient.
- Les **Autocollants** viennent de tes serveurs.
- **GIF :** recherche, tendances et catégories. Survole un GIF et clique sur l'étoile pour le garder dans tes **Favoris**.

## Réactions

Survole un message et choisis parmi tes émojis les plus utilisés, ou clique sur **Ajouter une réaction** pour le sélecteur complet. **Ajouter une super réaction** en ajoute une animée.

Clique sur une réaction sous un message pour ajouter la tienne, et clique à nouveau pour la retirer. Survole une réaction pour voir qui a réagi, ou choisis **Voir les réactions** dans le menu du message.

## Répondre, modifier et supprimer

- **Répondre** cite l'original au-dessus de ton message et prévient son auteur. Appuie sur <kbd>Esc</kbd> pour annuler.
- **Modifier le message** change ce que tu as écrit. Les messages modifiés indiquent **(modifié)**. Clique dessus pour voir les versions précédentes.
- **Supprimer le message** le supprime pour tout le monde.

Cliquez sur la ligne citée au-dessus d’une réponse pour voir le message auquel elle répond. **Retour** dans la barre du bas, ou <kbd>Esc</kbd>, vous ramène là où vous étiez.

## Le menu du message

Fais un clic droit sur un message, clique sur son bouton **⋯**, ou fais un appui long dessus sur téléphone. Tu y trouveras :

- **Répondre**, **Transférer**, **Créer un fil**
- **Copier le texte** et **Copier le lien du message**
- **Épingler le message**. Les épingles sont listées sous le bouton épingle de la barre du haut (<kbd>Ctrl</kbd>+<kbd>P</kbd>).
- **Ajouter le message aux favoris** : le garder pour plus tard dans ta [boîte de réception](notifications#your-inbox)
- **Me le rappeler** : dans 20 minutes, une heure, 3 heures, demain ou la semaine prochaine
- **Marquer comme non lu** : y revenir plus tard
- **Traduire**, si le serveur le propose, et **Lire le message à voix haute** pour l'écouter
- **Retirer les intégrations**, pour masquer un aperçu de lien
- **Signaler le message**, pour tout ce qui enfreint les règles

## Fichiers, images et vidéos

Clique sur **+** puis **Importer un fichier**, fais glisser des fichiers dans la discussion, ou colle-les.

- Jusqu'à 10 fichiers par message, normalement 25 Mo chacun. L'hébergeur de ton serveur peut autoriser plus.
- Avant d'envoyer, tu peux **Marquer comme spoiler** ou **Ajouter un texte alternatif** : une description pour les personnes qui utilisent un lecteur d'écran.
- Les images s'ouvrent en grand quand on clique dessus. Les vidéos et l'audio se lisent directement dans la discussion.

## Messages vocaux

Clique sur **+** puis **Enregistrer un message vocal**. Parle, puis envoie-le ou jette-le. Ceux qui l'écoutent peuvent l'accélérer à 1,5× ou 2×. Si le serveur a activé les transcriptions, ils peuvent aussi le lire.

## Sondages

Clique sur **+** puis **Créer un sondage** :

1. Écris une question et de 2 à 10 réponses. Chaque réponse peut avoir un émoji.
2. Choisis si les gens peuvent sélectionner plusieurs réponses.
3. Choisis sa durée, d'1 heure à une semaine, ou sans fin.
4. Clique sur **Publier le sondage**.

Les résultats se mettent à jour en direct. La personne qui a créé le sondage peut le clôturer plus tôt.

## Programmer un message

Écris ton message, puis fais un clic droit sur le bouton **Envoyer** (sur téléphone, un appui long) et choisis **Programmer le message**. Choisis un moment comme **Demain matin**, ou choisis **Personnalisé**.

Tu peux avoir jusqu'à 30 messages programmés. Retrouve-les sous **Programmés** dans ta [boîte de réception](notifications#your-inbox), où tu peux les **Envoyer maintenant**, les modifier ou les supprimer.

## Transférer

**Transférer** envoie une copie d'un message vers d'autres salons ou personnes. Elle est marquée *Transféré* et reste même si l'original est supprimé.

## Commandes slash

Tape `/` au début de la zone pour voir les commandes disponibles :

| Commande | Effet |
|---|---|
| `/shrug` `/tableflip` `/unflip` `/lenny` | Ajoute la frimousse à ton message |
| `/me` | Envoie ton message en italique, comme une action |
| `/spoiler` | Masque tout ton message jusqu'au clic |
| `/tts` | Lit ton message à voix haute pour tous ceux qui regardent le salon |
| `/nick` | Change ton pseudo sur ce serveur |

Les applis et les bots du serveur ajoutent leurs propres commandes. Voir [Applis et bots](apps-and-bots).

## Résumés

Salon très actif ? Le bouton **Résumés** dans la barre du haut donne un résumé rapide des deux derniers jours. Les résumés sont rédigés automatiquement, alors vérifie les messages d'origine avant de t'y fier. Les serveurs peuvent désactiver cette fonction.
