Appuie sur <kbd>Ctrl</kbd>+<kbd>/</kbd> dans Parley pour voir cette liste à tout moment. Sur Mac, utilise <kbd>⌘</kbd> partout où il est écrit <kbd>Ctrl</kbd>.

## Se déplacer

| Touches | Effet |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Sélecteur rapide : aller à n'importe quel serveur, salon ou personne |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Salon précédent / suivant |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Salon non lu précédent / suivant |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Serveur précédent / suivant |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Ouvrir ta boîte de réception |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Messages épinglés |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Afficher ou masquer la liste des membres |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Aller à une date |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Paramètres utilisateur |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Retour / avance (appli de bureau) |

## Messages

| Touches | Effet |
|---|---|
| <kbd>Enter</kbd> | Envoyer |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nouvelle ligne |
| <kbd>↑</kbd> (dans une zone vide) | Modifier ton dernier message |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Aller à la zone de saisie |
| <kbd>Esc</kbd> | Annuler une réponse, ou marquer le salon comme lu |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Marquer tout le serveur comme lu |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Mettre la sélection en gras / italique / souligné |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Barré |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Code |

Commence à taper n'importe où et tes mots arrivent dans la zone de saisie.

## Voix

| Touches | Effet |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Couper ou réactiver le micro |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Activer ou désactiver la sourdine |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Enregistrer un clip de l'appel |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Activer ou désactiver le mode streamer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Overlay en jeu (appli de bureau) |

## Modifier les raccourcis

Ouvre **Paramètres utilisateur → Raccourcis clavier** pour modifier n'importe lequel d'entre eux, ou pour ajouter une touche **Appuyer pour parler**. L'appli de bureau peut aussi écouter certains raccourcis pendant que tu es dans une autre appli, comme un jeu.
