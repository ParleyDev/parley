اضغط <kbd>Ctrl</kbd>+<kbd>/</kbd> في Parley لترى هذه القائمة في أي وقت. وعلى Mac، استخدم <kbd>⌘</kbd> حيثما ورد <kbd>Ctrl</kbd>.

## التنقل

| المفاتيح | ما تفعله |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | المبدّل السريع: انتقل إلى أي خادم أو قناة أو شخص |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | القناة السابقة / التالية |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | القناة غير المقروءة السابقة / التالية |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | الخادم السابق / التالي |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | فتح بريدك الوارد |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | الرسائل المثبتة |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | إظهار قائمة الأعضاء أو إخفاؤها |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | الانتقال إلى تاريخ |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | إعدادات المستخدم |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | الرجوع / التقدم (تطبيق سطح المكتب) |

## الرسائل

| المفاتيح | ما تفعله |
|---|---|
| <kbd>Enter</kbd> | إرسال |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | سطر جديد |
| <kbd>↑</kbd> (في مربع فارغ) | تعديل رسالتك الأخيرة |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | الانتقال إلى مربع الرسالة |
| <kbd>Esc</kbd> | إلغاء الرد، أو تعليم القناة كمقروءة |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | تعليم الخادم كله كمقروء |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | جعل النص المحدد غامقًا / مائلًا / مسطّرًا |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | يتوسطه خط |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | رمز برمجي |

ابدأ الكتابة في أي مكان وستذهب كلماتك إلى مربع الرسالة.

## الصوت

| المفاتيح | ما تفعله |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | كتم الميكروفون أو إلغاء كتمه |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | كتم السماعة أو إلغاء كتمها |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | حفظ مقطع من المكالمة |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | تشغيل وضع البث أو إيقافه |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | طبقة العرض داخل الألعاب (تطبيق سطح المكتب) |

## تغيير الاختصارات

افتح **إعدادات المستخدم ← اختصارات المفاتيح** لتغيير أي منها، أو لإضافة مفتاح **اضغط للتحدث**. ويمكن لتطبيق سطح المكتب أيضًا التقاط بعض الاختصارات وأنت في تطبيق آخر، مثل لعبة.
