## 未読メッセージ

- 新しいメッセージがあるチャンネルは **太字** になります。
- 新しいメッセージがあるサーバーには小さな点が付きます。
- 赤い数字は、誰かがあなたをメンションしたか、DMを送ったことを表します。

チャンネルの中では、上部のバーに新着メッセージの数が表示され、**新規** の線で新着の始まりがわかります。

未読の印を消すには：

- <kbd>Esc</kbd> でチャンネルを既読に、<kbd>Shift</kbd>+<kbd>Esc</kbd> でサーバー全体を既読にします。
- または、チャンネル、サーバー、DMを右クリックして **既読にする** を選びます。

後で読み返したいときは、メッセージで **未読にする** を使います。

## 通知する内容を選ぶ

サーバー、カテゴリー、チャンネル、DMを右クリックする（またはサーバーメニューを使う）と、2つの選択肢があります。

- **ミュート**：15分、1時間、8時間、24時間、または **再度オンにするまで**。ミュートした場所には未読の印が付かなくなりますが、あなた宛ての直接のメンションは届きます。
- **通知設定**：
  - **すべてのメッセージ**
  - **@メンションのみ**
  - **なし**
  - **サーバーのデフォルトを使用**（チャンネルのみ）

サーバー全体の設定は、サーバーメニューを開いて **通知設定** を選びます。上記に加えて、次のこともできます。

- `@everyone`、`@here`、ロールへのメンションを無視する
- ハイライトと新しいイベントのお知らせをオフにする
- そのサーバーのプッシュ通知をスマートフォンで受け取るかどうかを選ぶ
- 特定のチャンネルに別のルールを設定する

> Tip: 盛り上がっているサーバーは、サーバーを **@メンションのみ** にしておき、本当に大事な1つか2つのチャンネルだけを **すべてのメッセージ** にするのがおすすめです。

## 受信トレイ

右上の受信トレイボタン（<kbd>Ctrl</kbd>+<kbd>I</kbd>）には、あなたを待っているものがすべて集まります。

| タブ | 内容 |
|---|---|
| **未読** | 新しいメッセージがあるチャンネル。**すべて既読にする** で消せます。 |
| **メンション** | 過去30日間に誰かがあなたをメンションしたもの。 |
| **ブックマーク** | 保存したメッセージ。フォルダーに分けて整理できます。 |
| **リマインダー** | リマインドを頼んだメッセージ。 |
| **ハイライト** | ここ2日間にサーバーで目立ったもの。 |
| **予約済み** | 予約したメッセージ。今すぐ送信、編集、削除ができます。 |

## デスクトップ、スマートフォン、メールの通知

**ユーザー設定 → 通知** で：

- **デスクトップ通知を有効にする** と、新しいメッセージが来たときにお知らせが出ます。
- **このブラウザのプッシュ通知** をオンにすると、Parleyのタブを閉じていても通知が届きます。通知から返信したり既読にしたりできます。
- **未読メッセージバッジを有効にする** と、タブやアプリのアイコンに件数が表示されます。
- **誰かが私のメッセージに返信したときに通知する** を使うと、返信をメンションと同じように扱います。
- **スマートフォン：** Parleyアプリをインストールしていれば、パソコンで操作している間はスマートフォンが静かになります。**スマートフォンにテスト通知を送信** で動作を確認できます。
- **メール通知** は、オフラインのときだけ、最大で1時間に1通送られます。
- **サウンド：** どの音を鳴らすか、どれくらいの音量にするかを選べます。

イベントのリマインダーは、**興味あり** を付けたイベントの開始10分前に届きます。
