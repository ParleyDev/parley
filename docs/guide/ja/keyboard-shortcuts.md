Parleyで <kbd>Ctrl</kbd>+<kbd>/</kbd> を押すと、いつでもこの一覧を表示できます。Macでは、<kbd>Ctrl</kbd> と書かれているところで <kbd>⌘</kbd> を使ってください。

## 移動

| キー | 動作 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | クイックスイッチャー：どのサーバー、チャンネル、人にも移動 |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 前 / 次のチャンネル |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 前 / 次の未読チャンネル |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | 前 / 次のサーバー |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | 受信トレイを開く |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | ピン留めされたメッセージ |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | メンバーリストの表示・非表示 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | 日付へ移動 |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | ユーザー設定 |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | 戻る / 進む（デスクトップアプリ） |

## メッセージ

| キー | 動作 |
|---|---|
| <kbd>Enter</kbd> | 送信 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 改行 |
| <kbd>↑</kbd>（空の入力欄で） | 最後のメッセージを編集 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | メッセージ入力欄へ移動 |
| <kbd>Esc</kbd> | 返信をキャンセル、またはチャンネルを既読にする |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | サーバー全体を既読にする |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | 選択範囲を太字 / 斜体 / 下線にする |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 取り消し線 |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | コード |

どこで入力し始めても、文字はメッセージ入力欄に入ります。

## ボイス

| キー | 動作 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | ミュート・ミュート解除 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | スピーカーミュート・解除 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | 通話のクリップを保存 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | 配信者モードのオン・オフ |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | ゲーム内オーバーレイ（デスクトップアプリ） |

## ショートカットを変更する

**ユーザー設定 → キー割り当て** を開くと、これらを変更したり、**プッシュトゥトーク** のキーを追加したりできます。デスクトップアプリでは、ゲームなどほかのアプリを使っている間も一部のショートカットが反応します。
