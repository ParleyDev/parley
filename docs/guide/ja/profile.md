プロフィールは、ほかの人があなたの名前をクリックしたときに表示されるものです。左下の自分のアイコンから **プロフィールを編集** を選ぶと、エディターが開きます。

![右側にカードのライブプレビューがあるプロフィールエディター](shot:profile-editor)

エディターでは、編集しながらカードのプレビューを確認できます。プレビューの名前、代名詞、ステータス、アイコン、バナーをクリックすると、その項目に直接移動します。**変更を保存** をクリックするまで、ほかの人には何も変わりません。

## 基本

| 項目 | 説明 |
|---|---|
| **表示名** | ほかの人に表示される名前。最大32文字。 |
| **代名詞** | 最大40文字。 |
| **自己紹介** | 最大400文字。書式も使えます。 |
| **アバター** | PNG、JPEG、GIF、WebP、最大8 MB。アニメーション画像は動いたまま表示されます。円形に切り抜き、**最近のアバター** から以前のものに戻すこともできます。 |
| **バナー** | カードの上部にある横長の画像。5:2に切り抜かれます。1200×480ピクセル前後がおすすめです。 |
| **プロフィールテーマ** | カードを上から下へ色づける2つの色。 |

**ユーザー名** は表示名とは別のものです。**ユーザー設定 → アカウント** で変更でき、変更できるのは1日1回までです。

## ネームプレート、デコレーション、エフェクト、フレーム

これらで個性を出せます。

- **ネームプレート**：メンバーリストで名前の後ろに表示される背景。
- **アバターデコレーション**：アイコンの周りのリングや飾り。
- **プロフィールエフェクト**：カードの上で再生されるアニメーション。
- **プロフィールフレーム**：カード全体を囲む枠。

エディターでこれらのタイルをクリックすると、それぞれのピッカーが開きます。

![アバターデコレーションを選んで、すべてのサイズでプレビューしているところ](shot:cosmetic-picker)

1. グリッドを眺めるか、名前やタグで検索します。検索欄の下のタグをクリックすると、そのタグが付いたものだけが表示されます。もう一度クリックするとすべて表示に戻ります。**なし** を選ぶと、今付けているものが外れます。
2. 候補にカーソルを合わせるかクリックすると、ほかの人に見えるのとまったく同じ場所でプレビューできます。デコレーションはすべてのサイズで、ネームプレートはメンバーリストで、エフェクトとフレームはカード全体で表示されます。
3. **適用** をクリックするか、候補をダブルクリックします。残すには **変更を保存** を押してください。

グリッドはスクロールに合わせて読み込まれ続けるので、すべての候補を見られます。**内蔵** のものはParleyに最初から入っているもの、**このサーバーから** のものは、利用しているParleyサーバーの運営者が追加したものです。

### 見つけるですべてを眺める

コレクション全体を一度に見るには、**見つける**（サーバー一覧のコンパス）を開いて **プロフィールスタイル** を選びます。各カードにはアイテムをプロフィールに付けたときの見た目が表示されます。カードを開くと自分のプロフィールで試せます。

- 右側の **アイテムの種類** で、アイテムの種類を1つ以上チェックするか、**バンドル**（組み合わせのセット）や **コレクション** を選びます。並べ替えは **人気**、**新しい順**、**A–Z** から選べます。
- ほかのフィルターでは色、テーマ、タグで絞り込めます。見本のない色は名前で表示されます。検索欄に `#` とタグを入力するとタグだけを検索します。**フィルターを隠す** で折りたためます。スマホでは **フィルターを表示** で全画面で開きます。
- 複数のスタイルがあるデザインは 1 枚のカードにまとまっています。カードをクリックすると、スタイルの一覧、プロフィールでのプレビュー、含まれるセットが見られます。
- **身につける** を押すと、保存しなくてもすぐにプロフィールに反映されます。**セットを試す** でバンドル全体をプロフィールでプレビューでき、**すべて身につける** でセットの中身をまとめて身につけます。

## 表示名のスタイル

**表示名のスタイル** では、名前のフォント、エフェクト、色を設定します。迷ったら **おまかせ** を試してみましょう。サーバー内では、色付きのロールが名前の色より優先されます。

- **フォント**：**スラブ**、**バブリー**、**レトロ** から **ピクセル**、**中世**、**手書き**、**タイプライター** まで、14種類の書体があります。どのデバイスでも同じに見えます。日本語やアラビア語など、フォントにない文字はParleyの標準フォントで表示されます。
- **エフェクト**：**実線**、**グラデーション**、**ネオン**、**トゥーン**、**ポップ**、**グミ**、**レインボー**、**グリッチ**、**ウェーブ**、**クローム**。グラデーションとポップは2色、グミは3色で1文字ずつ順番に色を付け、レインボーは5色を使います（Holoなどのパレットを選ぶか、自分で決めます）。
- エフェクトは名前にカーソルを合わせるまで止まっていて、プロフィールカードでは常に再生されます。この動作の変更やオフは **設定 → アクセシビリティ** でできます。

## タグとバッジ

- **クランタグ**：どこでも名前の横に表示される、2〜4文字の英数字。
- **サーバータグ**：参加しているサーバーにタグがあれば、それを付けられます。
- **ハウスバッジ**：House of Ember、Tide、Groveのどれかに入れます。自分のハウスをもう一度クリックすると抜けられます。
- **バッジ**はプロフィールカードの名前の横に表示されます。このParleyサーバーを運営する人には**インスタンス管理者**、最初の10アカウントには**ファウンダー**、1年以上いる人には**ベテラン**、あなたのハウス、そしてこのサーバーの管理者が作って特別な理由で付与したバッジです。バッジにポインターを合わせると意味が表示されます。

## ステータス

左下の自分のアイコンをクリックします。

- **オンライン**、**退席中**、**取り込み中**（通知のポップアップや音が出ません）、**オフライン表示**（オフラインに見えますが、すべての機能を使えます）。一定時間だけ設定することもでき、時間が過ぎるとParleyが元に戻します。
- **カスタムステータスを設定**：絵文字と最大128文字のひとこと。決めた時間が過ぎたら消すか、自分で消すまで残せます。

カスタムステータスは、プロフィールカードのアイコンの横にある吹き出しに表示されます。長いステータスは最初の2行だけが表示され、吹き出しにカーソルを合わせると全文を読めます。ほかの人のカードでは、吹き出しにカーソルを合わせると返事ができます。

- **リアクションを送信** を押すと絵文字パネルが開き、選んだ絵文字が相手に送られます。
- **返信** を押すと、カードが暗くなり、ステータスの下に入力欄が開きます。返信を入力して <kbd>Enter</kbd> を押すか、<kbd>Esc</kbd> で閉じます。

どちらも相手とのダイレクトメッセージに届き、その時点のステータスを引用した「*名前*さんのステータスに返信しました」または「*名前*さんのステータスにリアクションしました」という行の下に表示されます。誰かがあなたのステータスに返事をした場合は「あなたのステータス」と表示されます。

Spotifyを接続すると（**ユーザー設定 → 接続**）、ほかの人にあなたが聴いている曲が表示されます。

## サーバーごとに違うプロフィール

サーバーごとに見た目を変えられます。たとえば、あるサーバーでは仕事向きのアイコン、別のサーバーではおふざけのアイコン、という具合です。サーバーメニューを開いて **サーバープロフィールを編集** を選ぶか、エディターの **サーバープロフィール** タブを使います。次の項目を設定できます。

- **サーバーニックネーム**
- **サーバーアバター** と **サーバーバナー**
- **代名詞** と **自己紹介**

空欄にした項目には、メインのプロフィールが使われます。メッセージ入力欄で `/nick` を使えば、ニックネームだけを変更することもできます。

## プロフィールを見られる人

エディターの **プロフィール全体を閲覧できる人** は、**全員** か **フレンドのみ** から選べます。ウィッシュリストやゲームなどの任意のセクションは、入力した場合にだけ表示されます。
