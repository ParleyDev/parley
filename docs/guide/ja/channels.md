どのサーバーも、話題や活動ごとの **チャンネル** に分かれています。チャンネルは折りたためる **カテゴリー** にまとめられています。

## チャンネルの種類

| アイコン | 種類 | 用途 |
|---|---|---|
| `#` | **テキスト** | 普段のチャット：メッセージ、画像、GIF、リンク。 |
| 📢 | **お知らせ** | 大事なお知らせ。ほかのサーバーが **フォロー** すると、自分のサーバーのチャンネルで投稿を受け取れます。 |
| 🔊 | **ボイス** | 気軽に入って話せます。ビデオや画面共有もでき、それぞれに専用のテキストチャットもあります。 |
| 🎙 | **ステージ** | トークやイベント向け：少数のスピーカーが話し、ほかの人は聴いて挙手できます。 |
| 💬 | **フォーラム** | ひと続きのチャットではなく、タイトルとタグ付きの投稿で整理されます。 |
| 🖼 | **メディア** | どの投稿も画像や動画が先頭に来るフォーラムで、ギャラリーとして表示されます。 |
| 📚 | **ディレクトリ** | メンバーが見て参加できる、ほかのサーバーの一覧。 |
| 🎚 | **レコーディングスタジオ** | 一緒に音楽を作ります。[スタジオ](studio)をご覧ください。 |

チャンネルに小さな鍵が付いていたら **非公開** です。一部のロールや人だけが見られます。

入る前にお知らせが表示されるチャンネルもあります。

- **年齢制限付き** チャンネルは、18歳以上と確認された人だけが利用できます。確認済みの場合は、一度だけ警告が表示され、そのあと入れます。確認されていない場合は、チャンネルにロックと、確認を受ける方法が表示されます。[あなたの年齢](settings#your-age)をご覧ください。
- **ネタバレ** チャンネルでは、画像や動画はクリックするまで隠れています。
- **スローモード** のチャンネルでは、一人ひとりが一定の間隔でしか投稿できません。あとどれくらい待てばいいかはメッセージ入力欄に表示されます。

## 表示するチャンネルを選ぶ

大きなサーバーは情報が多くて大変です。サーバーメニュー（サーバー名をクリック）を開いて **チャンネル一覧** を選びましょう。リストに表示したいチャンネルにチェックを入れ、それ以外はチェックを外します。そこで自分で選べるロールを用意しているサーバーもあります。

ほかにも整理する方法があります。

- **チャンネルをピン留め**（チャンネルを右クリック）すると、リストのいちばん上に固定されます。
- **ミュートしたチャンネルを非表示**（サーバーメニュー）で、ミュートしたチャンネルをリストから外せます。
- カテゴリーを右クリックすると、そのカテゴリー、またはすべてのカテゴリーを折りたためます。

## スレッド

スレッドは、ひとつのメッセージから枝分かれした脇道の会話です。メインのチャンネルを読みやすく保てます。

- **始めるには**、メッセージのメニューの **スレッドを作成** か、上部バーの **スレッド** ボタンを使います。名前を付けて、静かになってから非表示になるまでの時間（1時間〜1週間）を選びます。
- **非公開スレッド** にすると、追加した人（とモデレーター）だけのものになります。
- スレッドは最初のメッセージの下にカードとして表示されます。**スレッドを表示** をクリックすると、チャットの横に開きます。
- スレッドに **参加** すると、フォローして通知を受け取れます。やめるには **退出** します。
- スレッドを始めた人は、スレッドを閉じたり、アーカイブしたり、ロックしたりできます。古いスレッドはスレッド一覧の **アーカイブを表示** で見つかります。

## フォーラム

フォーラムチャンネルは、掲示板のような投稿の一覧です。投稿の一つひとつがスレッドになっています。

- **新規投稿** をクリックし、タイトル、メッセージ、タグ、必要ならファイルを付けます。
- **リスト** と **ギャラリー** を切り替えたり、**最新のアクティビティ** や **新しい投稿** で並べ替えたり、タグで絞り込んだりできます。
- **投稿を検索** で、タイトルから投稿を探せます。
- フォーラムに **投稿ガイドライン** があれば読んでおきましょう。投稿ごとにタグが必須のフォーラムもあります。

## お知らせチャンネル

お知らせチャンネルの投稿は、メッセージのメニューから **公開** できます。すると、フォローしているすべてのチャンネルに、ほかのサーバーであっても届きます。

あるサーバーのお知らせを自分のサーバーで受け取るには、チャンネルの上部バーで **フォロー** をクリックし、自分のサーバーとチャンネルを選びます。自分のサーバーでチャンネルを管理する権限が必要です。

## コミュニティ

とても大きなサーバーは、**コミュニティ** で整理できます。コミュニティはチャンネルのグループで、専用のページ、ヘッダー画像、管理者があります。

- チャンネルリストの **コミュニティを探す** で、すべてのコミュニティが見られます。気になるものは **フォロー** をクリックしましょう。
- フォローすると、チャンネルリストに表示されるものと未読として数えられるものが決まります。見られる範囲は変わりません。
- コミュニティの名前をクリックすると、そのページが開きます：概要、リンク、チャンネル、運営している人。

> Admins: コミュニティの管理者は **編集** でページを編集できます：ヘッダー画像、アイコン、説明、リンク。ヘッダーには専用のレイアウトエディター（**調整**）があり、塗りつぶしか収めるか、配置、ズームを設定できます。ヘッダーはウィンドウの幅いっぱいに伸びるので、スマートフォン、ノートパソコン、ワイド画面でプレビューできます。

## イベント

チャンネルの上にある **イベント** の行に、サーバーの今後のイベントが並びます。開催中のものには **開催中** と表示されます。**興味あり** をクリックすると参加の意思を伝えられ、開始10分前にParleyがお知らせします。
