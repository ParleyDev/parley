## ボイスチャンネルに参加する

ボイスチャンネル（🔊のもの）をクリックして **ボイスに参加** を選びます。誰がいるかが表示されます。話している人のアイコンは緑に光ります。

パネルの上の **ボイス接続** カードで、接続中であることがわかります。ここから次の操作ができます。

- 接続品質を確認する
- **ノイズ抑制** をオン・オフする
- 切断する

ボイス中でもテキストチャンネルでチャットを続けられます。ほかの場所に移動すると小さな通話ウィンドウがついてくるので、**通話に戻る** をクリックすれば戻れます。

> Tip: 初回は、Parleyがブラウザーにマイクの使用許可を求めます。誰にも声が聞こえない場合は、**ユーザー設定 → 音声・ビデオ** を確認し、**マイクテスト** を試してください。

## 通話のコントロール

| ボタン | 動作 |
|---|---|
| **ミュート** | マイクをオフにします。横の矢印で、マイク、スピーカー、音量を選べます。 |
| **カメラ** | カメラをオンにします。矢印でプレビューしたり、使うカメラを選んだりできます。 |
| **画面を共有** | ウィンドウ、タブ、または画面全体を表示します。 |
| **リアクション** | 通話の上に絵文字を浮かべます。 |
| **字幕** | 話している内容のライブ字幕です（サーバーが対応している場合）。 |
| **アクティビティ** | **一緒に観る**（YouTubeを同期再生）、**三目並べ** などのゲーム、アプリ。 |
| **サウンドボード** | サーバーの短いサウンドを全員に向けて再生します。 |
| **その他** | グリッド表示、自分のカメラやビデオなしの人を表示するかどうか。 |
| **切断** | 通話から抜けます。 |

誰かのビデオをクリックするとその人に注目し、ダブルクリックすると全画面になります。誰かが画面を共有したら、**配信を視聴** をクリックすると見られます。小さな文字はズームして読めます。

**スピーカーミュート**（パネルのヘッドホン）にすると、聞こえる音がすべてミュートされ、マイクも一緒にミュートされます。

## 通話をかける

DMやグループDMで、上部バーの **音声通話を開始** か **ビデオ通話を開始** をクリックします。相手には **参加** と **拒否** のある着信が表示されます。出られなかった場合は、着信があったことがわかります。

自分がいるボイスチャンネルにフレンドを呼ぶこともできます。**ボイスに招待** で、**参加** ボタン付きのメッセージが送られます。

## ステージ

ステージは、トーク、Q&A、ショー向けです。

- **スピーカー** はステージ上にいます。それ以外の人は **観客** として聴きます。
- 観客は **挙手** をクリックして発言を求められます。
- モデレーターは **発言に招待** と **観客に移動** ができます。
- 公開サーバーのライブ中のステージは **見つける → ステージ** に表示されます。

## プライベート通話

DMでの通話は **エンドツーエンド暗号化** できます。通話の内容を見聞きできるのは参加者だけで、サーバーでさえ見られません。DMの上部バーの鍵ボタンでオンにします。

誰も盗聴していないことを確かめるには、通話に表示される **安全コード** を声に出して照合しましょう。全員に同じコードが表示されていれば、その通話はプライベートです。暗号化された通話では、字幕とクリップは使えません。

## 音質を最適にする

**ユーザー設定 → 音声・ビデオ** で：

- **入力モード**：
  - **音声検出** では、話したときに音声を送ります。
  - **プッシュトゥトーク** では、キーを押している間だけ送ります。キーは **キー割り当てを記録** で設定します。ブラウザーではParleyのタブが前面にあるときだけ使えますが、デスクトップアプリならどこでも反応します。
- **入力感度** では、どれくらいの大きさの声で反応するかを設定します。キーボードの音が聞こえると言われない限り、自動のままにしておきましょう。
- **ノイズ抑制**：**強化** にすると、キーボード、ファン、周りの話し声を取り除きます。処理は自分のデバイス上で行われます。
- **エコー除去** と **自動ゲイン調整** は、ノートパソコンやスピーカーを使うときに役立ちます。
- **ビデオをテスト** でカメラをプレビューできます。画面共有の画質もここで設定します。

## クリップ

**ユーザー設定 → クリップ** をオンにすると、通話の直前15秒〜1分を保持しておけます。何かすごいことが起きたら、**クリップを保存**（または <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd>）で保存しましょう。

## ゲーム内オーバーレイ

デスクトップアプリでは、全画面のゲームの上に誰が話しているかを表示できます。**ユーザー設定 → 詳細設定** でオンにし、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> で表示・非表示を切り替えます。
