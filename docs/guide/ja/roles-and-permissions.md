**ロール** は、*モデレーター*、*アーティスト*、*新入り* のようにメンバーに付けるラベルです。ロールにはそれぞれ、そのメンバーが何をできるかを決める **権限** があります。名前の横に表示される色やアイコンを付けることもできます。

サーバーの全員には、自動的に **@everyone** ロールが付いています。このロールの権限が、全員ができることになります。

![サーバー設定のロールページ](shot:roles)

## ロールを作成する

1. **サーバー設定 → ロール** を開き、**ロールを作成** をクリックします。
2. 名前と色を決めます。必要に応じて：
   - **ロールアイコン**（絵文字または小さな画像）を付ける
   - メンバーリストで **ロールメンバーをオンラインメンバーとは別に表示** する
   - **誰でもこのロールを@メンションできるようにする**
   - **メンバーが自分でこのロールを選択できるようにする**
3. 必要な権限をオンにします。
4. **メンバー** タブで人を追加するか、メンバーリストで誰かを右クリックしてロールを選びます。

**ロールを複製** でロールをコピーできます。似たロールを作るときに便利です。

## どのロールが優先されるか

ロールは順番に並んでいて、上にあるロールほど下のロールより優先されます。ドラッグするか、**上に移動** と **下に移動** で並べ替えます。

- 自分の最上位のロールより下のロールしか管理できません。
- ロールの色が食い違うときは、最上位のロールの色が使われます。

**ロールとしてサーバーを表示** を使うと、そのロールを持つメンバーに見えるものをそのまま確認でき、設定をチェックできます。

## 権限

権限は、一般、メンバーシップ、テキスト、ボイス、スタジオに分かれています。特に重要なもの：

| 権限 | できること… |
|---|---|
| **管理者** | すべての操作ができ、チャンネルの制限もすべて無視します。付与は慎重に。 |
| **サーバー管理** | サーバーの名前、アイコン、設定を変更できます。 |
| **ロールの管理** | 自分より下のロールを作成・付与できます。 |
| **チャンネルの管理** | チャンネルを作成・編集・削除できます。 |
| **メンバーをキック / メンバーをBAN / メンバーをタイムアウト** | 人をモデレートできます。[モデレーション](moderation)をご覧ください。 |
| **メッセージの管理** | 誰のメッセージでも削除・ピン留めできます。 |
| **@everyone をメンション** | サーバー全体に通知できます。 |
| **招待を作成** | 新しい人を招待できます。 |
| **絵文字の管理** | 絵文字、スタンプ、サウンドを追加できます。 |
| **イベントの管理** | イベントを予定できます。 |
| **監査ログを表示** | 誰が何を変更したかを確認できます。 |

> Tip: まずは **@everyone** が閲覧とチャットをできるようにしておきましょう。次に、キック、タイムアウト、メッセージの管理の権限を持つ *モデレーター* ロールを追加します。管理者が必要な人はほとんどいません。

## チャンネルの権限

チャンネルを非公開にしたり、あるチャンネルでできることを変えたりするには：

1. チャンネルを右クリックして **チャンネルを編集** を選び、**権限** を開きます。
2. **プライベートチャンネル** をオンにすると、追加したロールと人以外には表示されなくなります。
3. または **ロールまたはメンバーを追加** を使い、それぞれの権限を **許可**（✓）、**拒否**（✗）、**継承**（/、サーバー全体の設定）に設定します。

カテゴリーにも権限があります。カテゴリーと同じ設定のチャンネルには **同期済み** と表示されます。変更した後に **今すぐ同期** を押すと、また同じ設定に戻ります。

## メンバーリスト

**サーバー設定 → メンバー** には全員が表示されます。検索、ロールでの絞り込み、各メンバーの参加方法の確認、ロールの付与や取り外しができます。複数の人をまとめて選んで、キックやBANをすることもできます。

## 連携ロール

リンクロールは、アカウントを接続した人（たとえばTwitchのサブスクライバー）に自動的に付与されるロールです。**連携サービス** で設定します。
