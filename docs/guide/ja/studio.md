**レコーディングスタジオ** チャンネルは、サーバーの中にある音楽の作業場です。**プロジェクト** の一つひとつが1曲で、それぞれにマルチトラックエディター、テイク、コメント、バージョン、チャットがあります。バンドのメンバーはライブで一緒に録音することも、時間のあるときにパートを追加することもできます。

![スタジオで開いたプロジェクト](shot:studio)

## プロジェクトを始める

レコーディングスタジオチャンネルを開いて **新しいプロジェクト** をクリックします。名前とテンポを決めてください。**プロジェクトの作成** の権限が必要です。

ほかの場所ですでに曲を始めている？**読み込む** で、Bitwig、Studio One、Cubaseなどの `.dawproject` ファイルや、Parley独自の `.parley-project` ファイルを開けます。

## 録音

1. **オーディオ** パネルでオーディオを設定します：出力と **録音レイテンシー**。**測定** をクリックすると、テイクがビートにぴったり合うようになります。
2. トラックを追加します：マイクや楽器には **オーディオ**、内蔵のシンセ、ドラムキット、サンプラーを使うなら **MIDI**。
3. トラックを録音待機にして録音を押します。**バンドを録音** すると、セッションの全員を再生位置から録音します。**ひとりで録音** では自分だけを録音します。テイクは最大30分です。

MIDIキーボードがない？パソコンのキーで音を弾けます：<kbd>A</kbd>〜<kbd>K</kbd> が白鍵で、<kbd>Z</kbd> と <kbd>X</kbd> でオクターブを変えます。

## アレンジと編集

| キー | 動作 |
|---|---|
| <kbd>Space</kbd> | 再生・停止 |
| <kbd>Home</kbd> | 先頭に戻る |
| <kbd>L</kbd> | ループのオン・オフ |
| <kbd>S</kbd> | 再生位置でクリップを分割 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | 複製 |
| <kbd>Q</kbd> | クオンタイズ（ノートをグリッドにスナップ） |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 元に戻す / やり直す |
| <kbd>Tab</kbd> | アレンジとミキサーを切り替え |

MIDIクリップをダブルクリックすると **ピアノロール** が開きます。ほかにも、メトロノームとカウントイン、マーカー、テンポチェンジ、音量やエフェクトのオートメーションレーンがあります。

**ミキサー** では、どのトラックにも音量、パン、ソロ、ミュート、エフェクト、センドがあります。

## エフェクト

各トラック、バス、マスターにはエフェクトラックがあります：EQ、フィルター、コンプレッサー、ゲート、リミッター、リバーブ、ディレイ、ドライブ、コーラス。**+ エフェクト** をクリックして追加します。エフェクトは上から順にかかります。カーソルを合わせると、移動や削除ができます。

![曲の再生中に、ギターのEQとコンプレッサー、ベースのフィルターのエフェクトウィンドウを並べて開いたところ](shot:studio-effects)

エフェクトをクリックするとウィンドウが開きます。ウィンドウはいくつでも開けて、どこへでもドラッグできます。ウィンドウをクリックすると前面に来ます。各ウィンドウにはエフェクトの働きが表示されます。

- **EQ** と **フィルター**：音のスペクトルの上に周波数カーブを表示します。カーブ上の点をドラッグして形を整えます。フィルターでは、上下にドラッグするかマウスホイールを使うと、レゾナンスを増減できます。
- **Compressor**（コンプレッサー）、**Gate**（ゲート）、**Limiter**（リミッター）：入力の大きさと出力の大きさの関係、今の音の位置を示す点、直近数秒のレベル、どれだけ音量が下げられているかを表示します。
- **Reverb**（リバーブ）：残響の形。**ディレイ**：消えていくそれぞれのエコー。**ドライブ**：歪みのカーブと、かける前後の音。**Chorus**（コーラス）：揺れの動き。

曲の再生中は、表示と **イン**・**アウト** のメーターが音に合わせて動きます。

設定を変えるには：

- ノブを上下にドラッグします。<kbd>Shift</kbd> を押しながらだと細かく調整できます。
- マウスホイールか矢印キーを使います。
- ノブの下に `2.5k` や `25%` のように値を入力します。
- ノブをダブルクリックするとデフォルトに戻ります。

ウィンドウのタイトルバーにある電源ボタンで、エフェクトをオン・オフします。矢印ボタンですべての設定をリセットします。

> Tip: ギターのEQとベースのフィルターのように、2つのトラックの同じエフェクトを並べて開き、曲を再生してみましょう。それぞれがどこに収まっているかが見え、お互いのためにスペースを空けられます。

### 例

どれもエフェクトのデフォルトの状態から始めます。作業中は曲を再生しておき、できれば **ループ** をオンにして、ウィンドウに自分の音が表示されるようにしましょう。

**ギターやボーカルの低域をすっきりさせる。** **EQ** を追加します。カーブ上の **C** の点を右へドラッグし、**ローカット** が約 `90 Hz` になるようにします。それより下のこもった低音が消え、カーブの後ろのスペクトルで何を削ったかがわかります。**M** の点を約 `2.5k` まで動かして数dB上げると、パートが前に出てきます。

**ボーカルの音量をそろえる。** **Compressor** を追加します。**レシオ** を `4:1` にし、カーブ上の点を見ながら **スレッショルド** を下げていきます。大きな言葉が折れ目を越えると、**GR** メーターにどれだけ音量が下げられたかが表示されます。いちばん大きな言葉で3〜6 dBくらいを目安にし、同じくらい **メイクアップ** を上げて、パートの音量を元に戻します。

**フィルターをスイープする。** シンセやドラムのトラックに **フィルター** を追加し、**ローパス** を選びます。曲を再生しながら、カーブ上の点を右から左へゆっくりドラッグします。カットオフが下がるにつれて音がこもっていきます。点を上下にドラッグするか、その上でマウスホイールを回すと **レゾナンス** が変わります。上げるほど、カットオフ付近に鋭く鳴るピークができます。スイープを曲の一部にするには、[オートメーションレーン](#arranging-and-editing)で記録してください。

**ノイズの多いトラックの、音と音の間のサーッという音を止める。** ラックの最初に **Gate** を追加します。ランプを見てください。パートが鳴っている間は **OPEN**、隙間では **CLOSED** と表示されます。隙間では閉じ、残したいいちばん小さな音では開いたままになるところまで **スレッショルド** を上げます。

**パートに部屋の響きを付ける。** **Reverb** を追加し、**ミックス** を約 `20%` にします。**ディケイ** を長くすると広い空間になり、**トーン** を下げると残響が暗くなって、元の音の後ろに収まります。

**ミックス全体のピークを抑える。** **マスター** に **Limiter** を追加し、**シーリング** は `-1 dB` のままにします。ウィンドウには、いちばん大きな瞬間がどれくらいの頻度で抑えられているかが表示されます。ずっと効きっぱなしなら、代わりにトラックの音量を下げましょう。

## バンドで作業する

- **バンド**：全員が **エンジニア**（何でも変更できる）か **アーティスト**（自分のパートを録音する）のどちらかです。**このトラックを保護** すると、ほかの人があなたのパートを編集できなくなります。
- **セッション**：エンジニアが **セッションを開始** をクリックすると、ライブで一緒に作業できます。誰かが再生した音は全員に聞こえます。
- **テイク**：録音はすべて残ります。**テイクを使う** でいちばんいいものを選びます。
- **コメント**：「ここでドラムがもたる」のように曲の特定の位置にメモを残し、対応したら **解決** します。
- **バージョン**：大きな変更の前に **バージョンを保存** しておき、気に入らなければ **復元** します。

バンドに入っていないリスナーも、曲を再生し、バンドの作業を追いかけ、コメントできます。

接続が切れた？そのまま作業を続けてください。変更は保存され、オンラインに戻ったときに送信されます。

## ほかの場所で作業する

チャットやほかのチャンネルに移動しても、プロジェクトの再生やテイクの録音は続きます。その間は、左下の名前の上にカードが表示され、プロジェクト、**プレイ中** か **録音** か、そして時間がわかります。プロジェクトのボイスルームにいる間も表示されます。チャンネルリストのその行には、再生中は動くバーが、録音中は赤い点が表示されます。

- カードのプロジェクト名をクリックすると、プロジェクトに戻ります。
- カードから停止や再生ができます。再生は止めたところから続きます。
- プロジェクトでテイクを止められる立場なら、カードからも止められます。
- 終わったら、停止してから **✕** をクリックしてカードを閉じます。

## 結果を共有する

**エクスポート** パネルでは次のことができます。

- ミックスをWAV、FLAC、MP3で書き出す
- **ステム**（トラックごとに分けてZIPにまとめたもの）を書き出す
- **ミックスをチャンネルに投稿** して全員に聴いてもらう
- ほかの音楽アプリで開けるよう、プロジェクトを `.dawproject` として保存する
