Pressione <kbd>Ctrl</kbd>+<kbd>/</kbd> no Parley para ver esta lista a qualquer momento. No Mac, use <kbd>⌘</kbd> onde estiver escrito <kbd>Ctrl</kbd>.

## Navegando

| Teclas | O que faz |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Seletor rápido: vá para qualquer servidor, canal ou pessoa |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Canal anterior / próximo |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Canal não lido anterior / próximo |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Servidor anterior / próximo |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Abrir sua caixa de entrada |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Mensagens fixadas |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Mostrar ou ocultar a lista de membros |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Ir para uma data |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Configurações de usuário |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Voltar / avançar (app para desktop) |

## Mensagens

| Teclas | O que faz |
|---|---|
| <kbd>Enter</kbd> | Enviar |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nova linha |
| <kbd>↑</kbd> (com a caixa vazia) | Editar sua última mensagem |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Ir para a caixa de mensagem |
| <kbd>Esc</kbd> | Cancelar uma resposta, ou marcar o canal como lido |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Marcar o servidor inteiro como lido |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Negrito / itálico / sublinhado na seleção |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Tachado |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Código |

Comece a digitar em qualquer lugar e suas palavras vão para a caixa de mensagem.

## Voz

| Teclas | O que faz |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Silenciar ou reativar o microfone |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Desativar ou reativar o áudio |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Salvar um clipe da chamada |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Ativar ou desativar o Modo streamer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Sobreposição no jogo (app para desktop) |

## Mudando os atalhos

Abra **Configurações de usuário → Atalhos de teclado** para mudar qualquer um destes, ou para adicionar uma tecla de **Pressionar para falar**. O app para desktop também consegue ouvir alguns atalhos enquanto você está em outro app, como um jogo.
