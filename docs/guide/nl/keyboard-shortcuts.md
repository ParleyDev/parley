Druk in Parley op <kbd>Ctrl</kbd>+<kbd>/</kbd> om deze lijst altijd te zien. Gebruik op een Mac <kbd>⌘</kbd> overal waar <kbd>Ctrl</kbd> staat.

## Navigeren

| Toetsen | Doet |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Snelkiezer: spring naar elke server, elk kanaal of elke persoon |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Vorig / volgend kanaal |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Vorig / volgend ongelezen kanaal |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Vorige / volgende server |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Je inbox openen |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Vastgezette berichten |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | De ledenlijst tonen of verbergen |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Naar een datum springen |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Gebruikersinstellingen |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Terug / vooruit (desktop-app) |

## Berichten

| Toetsen | Doet |
|---|---|
| <kbd>Enter</kbd> | Versturen |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nieuwe regel |
| <kbd>↑</kbd> (in een leeg vak) | Je laatste bericht bewerken |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Naar het berichtvak gaan |
| <kbd>Esc</kbd> | Een antwoord annuleren, of het kanaal als gelezen markeren |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | De hele server als gelezen markeren |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | De selectie vet / cursief / onderstreept maken |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Doorhalen |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Code |

Begin waar dan ook te typen en je woorden komen in het berichtvak.

## Spraak

| Toetsen | Doet |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Dempen of dempen opheffen |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Geluid uit of weer aan |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Een clip van het gesprek opslaan |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Streamermodus aan of uit |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | In-game overlay (desktop-app) |

## Sneltoetsen wijzigen

Open **Gebruikersinstellingen → Sneltoetsen** om een van deze te wijzigen, of om een toets voor **Push-to-talk** toe te voegen. De desktop-app kan ook naar sommige sneltoetsen luisteren terwijl je in een andere app zit, zoals een game.
