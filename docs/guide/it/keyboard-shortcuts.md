Premi <kbd>Ctrl</kbd>+<kbd>/</kbd> in Parley per vedere questo elenco in qualsiasi momento. Su Mac, usa <kbd>⌘</kbd> dove c'è scritto <kbd>Ctrl</kbd>.

## Spostarsi

| Tasti | Cosa fa |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Selettore rapido: vai a qualsiasi server, canale o persona |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Canale precedente / successivo |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Canale non letto precedente / successivo |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Server precedente / successivo |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Apri la posta in arrivo |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Messaggi fissati |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Mostra o nascondi l'elenco dei membri |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Vai a una data |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Impostazioni utente |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Indietro / avanti (app desktop) |

## Messaggi

| Tasti | Cosa fa |
|---|---|
| <kbd>Enter</kbd> | Invia |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | A capo |
| <kbd>↑</kbd> (con la casella vuota) | Modifica il tuo ultimo messaggio |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Vai alla casella del messaggio |
| <kbd>Esc</kbd> | Annulla una risposta, o segna il canale come letto |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Segna tutto il server come letto |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Grassetto / corsivo / sottolineato sulla selezione |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Barrato |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Codice |

Inizia a scrivere in qualsiasi punto e le tue parole finiscono nella casella del messaggio.

## Voce

| Tasti | Cosa fa |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Silenzia o riattiva il microfono |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Silenzia o riattiva l'audio |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Salva una clip della chiamata |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Attiva o disattiva la modalità streamer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Overlay in gioco (app desktop) |

## Modificare le scorciatoie

Apri **Impostazioni utente → Scorciatoie** per cambiarle, o per aggiungere un tasto per **Premi per parlare**. L'app desktop può anche ascoltare alcune scorciatoie mentre sei in un'altra app, per esempio un gioco.
