Naciśnij <kbd>Ctrl</kbd>+<kbd>/</kbd> w Parley, aby w każdej chwili zobaczyć tę listę. Na Macu używaj <kbd>⌘</kbd> wszędzie tam, gdzie jest <kbd>Ctrl</kbd>.

## Poruszanie się

| Klawisze | Działanie |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Szybki przełącznik: przejdź do dowolnego serwera, kanału lub osoby |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Poprzedni / następny kanał |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Poprzedni / następny nieprzeczytany kanał |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Poprzedni / następny serwer |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Otwórz skrzynkę odbiorczą |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Przypięte wiadomości |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Pokaż lub ukryj listę członków |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Przejdź do daty |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Ustawienia użytkownika |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Wstecz / dalej (aplikacja desktopowa) |

## Wiadomości

| Klawisze | Działanie |
|---|---|
| <kbd>Enter</kbd> | Wyślij |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Nowa linia |
| <kbd>↑</kbd> (w pustym polu) | Edytuj ostatnią wiadomość |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Przejdź do pola wiadomości |
| <kbd>Esc</kbd> | Anuluj odpowiedź albo oznacz kanał jako przeczytany |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Oznacz cały serwer jako przeczytany |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Pogrubienie / kursywa / podkreślenie zaznaczenia |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Przekreślenie |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Kod |

Zacznij pisać w dowolnym miejscu, a tekst trafi do pola wiadomości.

## Głos

| Klawisze | Działanie |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Wycisz lub włącz mikrofon |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Ogłusz lub cofnij ogłuszenie |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Zapisz klip z rozmowy |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Włącz lub wyłącz Tryb streamera |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Nakładka w grze (aplikacja desktopowa) |

## Zmienianie skrótów

Otwórz **Ustawienia użytkownika → Skróty klawiszowe**, aby zmienić dowolny z nich albo dodać klawisz **Naciśnij i mów**. Aplikacja desktopowa może też nasłuchiwać niektórych skrótów, gdy jesteś w innej aplikacji, np. w grze.
