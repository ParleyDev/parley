Press <kbd>Ctrl</kbd>+<kbd>/</kbd> in Parley to see this list at any time. On a Mac, use <kbd>⌘</kbd> wherever it says <kbd>Ctrl</kbd>.

## Getting around

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Quick switcher: jump to any server, channel or person |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Previous / next channel |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Previous / next unread channel |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Previous / next server |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Open your inbox |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Pinned messages |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Show or hide the member list |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd> | Jump to a date |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | User Settings |
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Back / forward (desktop app) |

## Messages

| Keys | Does |
|---|---|
| <kbd>Enter</kbd> | Send |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | New line |
| <kbd>↑</kbd> (in an empty box) | Edit your last message |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Go to the message box |
| <kbd>Esc</kbd> | Cancel a reply, or mark the channel read |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Mark the whole server read |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | Bold / italic / underline the selection |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Strikethrough |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Code |

Start typing anywhere and your words go into the message box.

## Voice

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Mute or unmute |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Deafen or undeafen |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Save a clip of the call |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Streamer Mode on or off |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | In-game overlay (desktop app) |

## Changing shortcuts

Open **User Settings → Keybinds** to change any of these, or to add a **Push to Talk** key. The desktop app can also listen for some shortcuts while you're in another app, such as a game.
