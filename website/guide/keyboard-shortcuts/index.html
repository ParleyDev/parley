Keyboard shortcuts

Keyboard shortcuts

Every shortcut, and how to change them.

Press Ctrl+/ in Parley to see this list at any time. On a Mac, use ⌘ wherever it says Ctrl.

#Getting around

KeysDoes
Ctrl+KQuick switcher: jump to any server, channel or person
Alt+↑ / ↓Previous / next channel
Alt+Shift+↑ / ↓Previous / next unread channel
Ctrl+Alt+↑ / ↓Previous / next server
Ctrl+IOpen your inbox
Ctrl+PPinned messages
Ctrl+UShow or hide the member list
Ctrl+Shift+JJump to a date
Ctrl+,User Settings
Alt+← / →Back / forward (desktop app)

#Messages

KeysDoes
EnterSend
Shift+EnterNew line
↑ (in an empty box)Edit your last message
Ctrl+Shift+EGo to the message box
EscCancel a reply, or mark the channel read
Shift+EscMark the whole server read
Ctrl+B / I / UBold / italic / underline the selection
Ctrl+Shift+SStrikethrough
Ctrl+ECode

Start typing anywhere and your words go into the message box.

#Voice

KeysDoes
Ctrl+Shift+MMute or unmute
Ctrl+Shift+DDeafen or undeafen
Ctrl+Alt+CSave a clip of the call
Ctrl+Shift+XStreamer Mode on or off
Ctrl+Shift+OIn-game overlay (desktop app)

#Changing shortcuts

Open User Settings → Keybinds to change any of these, or to add a Push to Talk key. The desktop app can also listen for some shortcuts while you're in another app, such as a game.
