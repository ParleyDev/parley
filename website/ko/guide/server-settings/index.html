서버 설정하기

이름, 아이콘, 배너, 초대, 채널, 이모지와 스티커, 환영과 온보딩, 템플릿 등.

서버 이름을 클릭해 서버 메뉴를 열고 서버 설정을 누르세요. 바꿀 권한이 있는 페이지만 보여요. 소유자에게는 모든 페이지가 보여요. 사용자 설정과 같은 창에서 열리며, 목록 맨 위 검색창에 입력하면 페이지를 찾을 수 있어요.

#이름, 아이콘, 배너

서버 프로필에서:

  • 아이콘: 최대 8 MB의 정사각형 사진.
  • 서버 이름: 최대 100자. 설명: 최대 300자.
  • 서버 배너: 채널 목록 맨 위의 사진. 16:9로 잘리며, 1920×1080이 가장 좋아요. 움직이는 GIF, APNG, WebP는 그대로 움직여요.
  • 시스템 메시지 채널: Parley가 새 멤버를 환영하는 곳. 원하면 멤버에게 인사하라고 알려 줄 수도 있어요.
  • 서버 규칙: 최대 4,000자. 멤버는 채팅하기 전에 규칙에 동의해야 해요를 체크하면 새로 온 사람이 먼저 동의해야 해요.
  • 새 멤버의 기본 알림 설정, 그리고 멤버가 메시지 예약하기를 할 수 있는지 여부.

사진을 고른 뒤 드래그하고 확대/축소해서 구도를 맞추세요. 나중에 다시 맞추려면 조정을 클릭하세요.

여기에는 이런 것도 있어요.

  • 서버 테마: 서버만의 색을 정해요. 멤버는 그 색으로 볼지 고를 수 있어요.
  • 서버 태그: 멤버가 이름 옆에 달 수 있는 짧은 태그와 배지.
  • 인사이트: 얼마나 많은 사람이 들어오고 머무는지, 얼마나 활발한지, 어떤 채널이 인기 있는지.

#사람 초대하기

서버 메뉴에서 친구 초대하기를 클릭하면 공유할 링크가 나와요. 서버 설정의 초대에서 맞춤 초대 링크를 만들 수 있어요.

  • 만료 시간: 30분부터 30일까지, 또는 무제한.
  • 최대 사용 횟수: 1부터 100까지, 또는 제한 없음.
  • 임시 멤버십 부여: 역할을 받지 않은 사람은 로그오프하면 자동으로 나가요.

활성 초대 링크가 모두 나열되고, 취소로 하나씩 없앨 수 있어요. 탐색에 등록된 공개 서버는 맞춤 고유 링크도 가질 수 있어요.

액세스: 직접 사람을 승인하려면 새 멤버가 채팅하기 전에 검토하기를 켜고 질문 몇 개를 쓰세요. 가입 신청은 내가 승인 또는 거절할 때까지 기다려요.

#채널과 카테고리

  • 채널 만들기는 서버 메뉴에 있고, 카테고리 옆의 +를 클릭해도 돼요. 종류는 채널을 참고하세요.
  • 채널과 카테고리를 드래그해서 순서를 바꾸세요.
  • 채널을 마우스 오른쪽 버튼으로 클릭하고 채널 편집하기를 고르면:
    • 주제와 슬로 모드
    • 연령 제한 및 스포일러 설정
    • 음성 채널: 사용자 수 제한, 영상 및 음성 품질, 종단 간 암호화
    • 포럼 태그
    • 권한: 역할과 권한을 참고하세요

#이모지, 스티커, 소리

한도파일
이모지서버당 100개512 KB 미만의 PNG, JPEG, GIF 또는 WebP. 이름은 문자, 숫자, _로 2~32자.
스티커서버당 60개1 MB 미만. 320×320픽셀이 가장 좋아요.
사운드보드서버당 48개512 KB 미만(약 5초)의 MP3, OGG, WAV, WebM 또는 M4A.

멤버는 내 서버의 커스텀 이모지를 자기가 속한 어떤 서버에서든 쓸 수 있어요.

#새 멤버 환영하기

  • 환영 화면: 누군가 들어오면 보여 주는 인사말과 최대 5개의 추천 채널.
  • 온보딩: 새로 온 사람에게 하는 질문("여기 어떻게 오셨어요?"). 답변마다 역할과 채널을 줄 수 있어서 관련 있는 것만 보이게 할 수 있어요. 질문을 필수로 정하거나 여러 답변을 허용하세요.
  • 규칙: 서버 프로필에서 정해요. 멤버는 동의해요를 클릭해야 글을 쓸 수 있어요.

#서버 안의 커뮤니티

큰 서버에서는 채널을 커뮤니티로 묶으세요. 커뮤니티마다 자체 페이지와 관리자가 있어요.

  • 채널 목록의 커뮤니티 옆 +로 만드세요.
  • 페이지를 열고 수정하기를 클릭하세요. 이런 것을 정할 수 있어요.
    • 아이콘, 이름, 설명
    • 웹 주소
    • 소개 섹션과 링크
    • 관리하는 사람과 채널
  • 헤더 이미지 추가하기로 페이지에 배너를 달아요.
    • 1600픽셀 이상의 넓은 사진이 가장 좋아요.
    • 조정을 클릭해 채우기 또는 맞추기를 고르고, 정렬 그리드로 위치를 맞추고, 확대/축소하세요.
    • 휴대폰, 노트북, 와이드 화면에서 어떻게 보이는지 미리 볼 수 있어요.
  • 커뮤니티 삭제는 편집 막대 맨 위에 있어요. 커뮤니티의 채널과 그 메시지도 함께 삭제돼요.

#서버 알리기

  • 서버 찾기: 카테고리, 설명, 배너와 함께 탐색에 서버를 올려요. 관리자가 먼저 검토해요.
  • 위젯: 웹사이트에 넣을 수 있는 상자로, 누가 온라인인지와 참여 버튼을 보여 줘요.
  • 배지: README나 웹사이트에 다는 실시간 "함께해요" 배지.

#서버 템플릿

서버 설정 → 서버 템플릿에서 서버 구성(역할, 카테고리, 채널, 권한, 몇 가지 설정)을 공유하면 다른 사람이 똑같은 서버를 시작할 수 있어요. 메시지, 멤버, 이모지는 절대 복사되지 않아요.

  • 템플릿 파일 다운로드하기는 현재 서버 상태를 .json 파일로 저장해요. 구성 백업으로 보관하거나 다른 사람에게 보내세요. 링크는 필요 없어요.
  • 링크 공유하기: 템플릿 제목과 설명을 쓰고 템플릿 생성을 누르세요. 링크는 바뀌지 않아요. 서버를 바꾼 뒤 템플릿 동기화를 클릭하면 링크가 새 구성을 전해요. 템플릿 삭제하기는 링크를 꺼요.

누구나 어느 Parley 서버에서든 서버 추가하기 → 템플릿 사용하기로 템플릿 파일이나 링크에서 서버를 만들 수 있어요. 템플릿으로 시작하기를 참고하세요.

템플릿 링크를 연 사람은 무엇이 설정되는지 보고, 그 템플릿으로 서버를 만들거나 파일로 다운로드할 수 있어요.

#넘겨주기 또는 닫기

목록 맨 아래에 있으며, 소유자만 쓸 수 있어요.

  • 소유권 이전하기는 서버를 다른 멤버에게 넘겨요.
  • 서버 삭제하기: 서버 이름과 비밀번호를 입력해서 확인하세요. 마음이 바뀌었나요? 7일 안에 사용자 설정 → 계정에서 복원할 수 있어요.
