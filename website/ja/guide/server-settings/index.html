サーバーの設定

名前、アイコン、バナー、招待、チャンネル、絵文字とスタンプ、ウェルカムとオンボーディング、テンプレートなど。

サーバー名をクリックしてサーバーメニューを開き、サーバー設定 を選びます。表示されるのは、変更する権限のあるページだけです。オーナーにはすべてのページが表示されます。ユーザー設定と同じウィンドウで開き、リストの上部にある検索ボックスに入力するとページを探せます。

#名前、アイコン、バナー

サーバープロフィール で：

  • アイコン：最大8 MBの正方形の画像。
  • サーバー名：最大100文字。説明：最大300文字。
  • サーバーバナー：チャンネルリストの上部に表示される画像。16:9に切り抜かれ、1920×1080が最適です。アニメーションGIF、APNG、WebPは動いたまま表示されます。
  • システムメッセージチャンネル：Parleyが新しいメンバーを歓迎する場所。メンバーにあいさつのウェーブを促すこともできます。
  • サーバールール：最大4,000文字。メンバーはチャットする前にルールに同意する必要があります にチェックを入れると、新しく来た人にまず同意してもらえます。
  • 新しいメンバーの デフォルトの通知設定 と、メンバーが メッセージを予約 できるかどうか。

画像を選んだら、ドラッグとズームで表示範囲を決めます。後から調整するには 調整 をクリックします。

ほかにもここで設定できます。

  • サーバーテーマ：サーバー独自の色を設定します。メンバーはそれを表示するかどうかを選べます。
  • サーバータグ：メンバーが名前の横に付けられる、短いタグとバッジ。
  • インサイト：何人が参加して残っているか、どれくらい活発か、どのチャンネルがいちばん人気か。

#人を招待する

サーバーメニューの 友達を招待 をクリックすると、共有用のリンクが表示されます。サーバー設定の 招待 では、カスタムの招待を作れます。

  • 有効期限：30分〜30日、または無期限。
  • 最大使用回数：1〜100回、または無制限。
  • 一時的なメンバーシップを付与：ロールを付与されていない限り、ログオフすると自動的にサーバーから抜けます。

有効な招待はすべて一覧表示され、取り消す で無効にできます。ディスカバリーに掲載された公開サーバーは、カスタムの バニティ リンクも使えます。

アクセス：手動で参加を承認するには、チャットする前に新規メンバーを審査する をオンにして、いくつか質問を書きます。申請はあなたが 承認 または 却下 するまで待機します。

#チャンネルとカテゴリー

  • チャンネルを作成 はサーバーメニューにあります。カテゴリーの横の + をクリックしても作れます。種類についてはチャンネルをご覧ください。
  • チャンネルやカテゴリーはドラッグで並べ替えられます。
  • チャンネルを右クリックして チャンネルを編集 を選ぶと、次の設定ができます。
    • トピックと スローモード
    • 年齢制限付き と ネタバレ の設定。年齢制限付きチャンネルは、18歳以上と確認されたメンバーだけが開けます。それ以外の人にはロックされた状態で表示されます。カテゴリーでオンにすると、その中のすべてのチャンネルが制限されます。オフに戻せるのは、自身が確認済みの人だけです。
    • ボイスの場合：ユーザー数の上限、映像と音声の品質、エンドツーエンド暗号化
    • フォーラムの タグ
    • 権限：ロールと権限をご覧ください

#絵文字、スタンプ、サウンド

上限ファイル
絵文字1サーバーあたり100個512 KB未満のPNG、JPEG、GIF、WebP。名前は英数字または _ で2〜32文字。
スタンプ1サーバーあたり60個1 MB未満。320×320ピクセルが最適です。
サウンドボード1サーバーあたり48個512 KB未満（約5秒）のMP3、OGG、WAV、WebM、M4A。

メンバーは、あなたのサーバーのカスタム絵文字を、参加しているどのサーバーでも使えます。

#新しいメンバーを迎える

  • ウェルカム画面：誰かが参加したときに表示される、おすすめのチャンネルを最大5つ載せたあいさつ。
  • オンボーディング：新しく来た人への質問（「ここに来た目的は？」など）。回答ごとにロールやチャンネルを付与できるので、関係のあるものが表示されます。質問を 必須 にしたり、複数回答を許可したりできます。
  • ルール：サーバープロフィールで設定します。メンバーは投稿する前に 同意する をクリックします。

#サーバー内のコミュニティ

大きなサーバーでは、チャンネルをコミュニティにまとめられます。それぞれに専用のページと管理者があります。

  • チャンネルリストの コミュニティ の横にある + で作成します。
  • ページを開いて 編集 をクリックします。次の項目を設定できます。
    • アイコン、名前、説明
    • Webアドレス
    • 概要 セクションと リンク
    • 管理する人と、チャンネル
  • ヘッダー画像を追加 で、ページにバナーを付けられます。
    • 横幅1600ピクセル以上の横長の画像がおすすめです。
    • 調整 をクリックして 塗りつぶし か 収める を選び、配置グリッドで位置を揃えて、ズームします。
    • スマートフォン、ノートパソコン、ワイド画面での見え方をプレビューできます。
  • コミュニティを削除 は編集バーの上部にあります。コミュニティのチャンネルとそのメッセージも削除されます。

#見つけてもらう

  • 発見：カテゴリー、説明、バナーを付けて、サーバーをディスカバリーに掲載します。まず管理者が審査します。
  • ウィジェット：Webサイトに埋め込めるボックスで、オンラインの人と 参加 ボタンが表示されます。
  • バッジ：READMEやWebサイト用の、ライブの「参加しよう」バッジ。

#サーバーテンプレート

サーバー設定 → サーバーテンプレート では、サーバーの構成（ロール、カテゴリー、チャンネル、権限、いくつかの設定）を共有して、ほかの人がそっくりのサーバーを始められるようにします。メッセージ、メンバー、絵文字はコピーされません。

  • テンプレートファイルをダウンロード すると、現在のサーバーを .json ファイルとして保存します。構成のバックアップとして取っておいたり、誰かに送ったりできます。リンクは不要です。
  • リンクを共有：テンプレートにタイトルと説明を付けて、テンプレートを生成 します。リンクは変わりません。サーバーを変更した後に テンプレートを同期 をクリックすると、リンクから新しい構成が使えるようになります。テンプレートを削除 するとリンクは無効になります。

テンプレートファイルやリンクからは、どのParleyサーバーでも サーバーを追加 → テンプレートを使う で誰でもサーバーを作れます。テンプレートから始めるをご覧ください。

テンプレートリンクを開いた人は、何が設定されるかを確認でき、そこからサーバーを作ったり、ファイルとしてダウンロードしたりできます。

#譲渡または閉鎖

リストのいちばん下にある、オーナー専用の項目です。

  • オーナー権限を譲渡 すると、サーバーをほかのメンバーに譲れます。
  • サーバーを削除：確認のためにサーバー名とパスワードを入力します。気が変わった？7日 以内なら ユーザー設定 → アカウント から復元できます。
