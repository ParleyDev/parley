アカウントのセキュリティ、プライバシー、外観、アクセシビリティ、言語、デスクトップアプリのオプション。

左下の名前の横にある歯車か Ctrl+, で ユーザー設定 を開きます。見つからない項目があるときは、リストの上部にある検索ボックスに入力してください。インスタンス管理者には、リストのいちばん下に 管理コンソール も表示されます。

#アカウント

  • アカウント情報：表示名、ユーザー名、メールアドレスを変更します。新しいメールアドレスは、まずリンクで確認されます。
  • パスワード：パスワードを変更します。同時にほかのすべての場所からログアウトすることもできます。
  • 2段階認証：強くおすすめします。2段階認証を有効にする をクリックし、認証アプリでコードをスキャンして、6桁のコードを入力するとオンになります。
    • バックアップコード は安全な場所に保管してください。スマートフォンをなくしたときに、これでログインできます。
  • パスキー：指紋、顔、デバイスのPINでログインします。パスキーを追加 をクリックしてください。モデレーターに2段階認証を求めるサーバーでは、パスキーも2段階認証として扱われます。
  • アカウントの状態：最近ルール違反をしたかどうか。通常は 問題なし と表示されます。お使いのParleyの運営者があなたのアカウントを制限している場合は、いつまでか、その間に何ができないかがここに表示されます。
  • 年齢：あなたの年齢をご覧ください。
  • サーバーBAN：あなたをBANしたサーバー。サーバーが認めていれば このBANに異議を申し立てる ができます。
  • ストレージ：アップロード容量をどれくらい使っているか。
  • 年間振り返り：Parleyでのあなたの1年。
  • アカウントの削除：アカウントを無効化または削除します。はじめにをご覧ください。

#あなたの年齢

Parleyは生年月日を尋ねません。成人と確認されるまでは、あなたのアカウントを年少の人のアカウントと同じように扱います。

  • 年齢制限付きチャンネルと成人限定サーバーには入れません。
  • 追加していない相手からのメッセージはリクエストとして届き、承認するまで画像、ファイル、リンクプレビューは非表示になります。

ユーザー設定 → マイアカウント → 年齢 には、現在の状態と、お使いのParleyで利用できる確認方法が表示されます。

  • 確認サービスが設定されている場合は、（サービス名）で確認。サービスがParleyに伝えるのは、あなたが18歳以上かどうかだけです。
  • 成人であることの確認をスタッフにリクエストする。スタッフから連絡が来ることがあります。本人確認書類をParley経由で送らないでください。
  • 18歳以上です。お使いのParleyが自己申告を認めている場合に表示されます。

どれも表示されない場合、お使いのParleyにはまだ年齢を確認する手段がありません。

  • 18歳未満です を選ぶと、アカウントが10代のアカウントとしてマークされます。メッセージを送れるのはフレンドだけになり、センシティブなメディアはぼかされるかブロックされ、ファミリーセンターを使えるようになります。元に戻せるのは管理者だけです。
  • 誕生日（任意） には、年を除いた月と日を保存できます。自分にだけ表示されます。
補足 あなたの年齢の状態は、ほかの誰にも見えません。

#データとプライバシー

  • ほかの人のDMを 既読 にしたこと、入力中 であること、何をしているか（アクティビティステータス）をほかの人に見せるかどうかを選べます。
  • 自分のデータをすべてリクエスト すると、Parleyが保持しているあなたに関するすべての情報のダウンロードを準備します。1日以内に用意され、7日間保管されます。
  • 信頼するリンク先：確認なしで開くようParleyに指定したWebサイト。

#コンテンツとソーシャル

  • DMを送れる人：全員、フレンドとサーバーメンバー、フレンドのみ。知らない人からのメッセージはメッセージリクエストに入ります。
  • フレンドリクエストを送れる人、そして検索であなたを見つけられるかどうか。
  • センシティブなメディア：表示、ぼかし、フィルター、非表示から選べます。フレンドからのDM、ほかの人からのDM、サーバー、年齢制限付きチャンネルで別々に設定できます。
  • DMスパムフィルター：スパムの可能性があるものをどれくらい厳しくフィルターするか。
  • セーフティセンター には、安全に過ごすためのヒントとリンクがあります。

#ファミリーセンター

保護者と10代の子どもはアカウントをリンクできます。保護者は、子どもがどのサーバーに参加したか、誰をフレンドに追加したか、誰とメッセージをやり取りしたかがわかりますが、メッセージの内容は見られません。子どもは 保護者をリンク でコードを受け取り、保護者がそれを 10代のアカウントをリンク に入力します。どちらからでも リンク解除 できます。

コードは、18歳未満としてマークされたアカウントで発行できます。あなたの年齢をご覧ください。

#デバイスと接続

  • デバイス には、ログインしているすべての場所が表示されます。デバイスを1台ずつログアウトしたり、誰かにアカウントを使われていないか心配なときは 他のすべてのデバイスをログアウト したりできます。
  • 接続 では、GitHub、Twitch、Spotify、Steamを連携し、必要ならプロフィールに表示できます。
  • 認証済みアプリ には、アカウントへのアクセスを許可したアプリやAIアシスタントが表示されます。アプリとBotをご覧ください。

#外観

  • テーマ：ライト、アッシュ、ダーク、オニキス、ミッドナイト。カラーテーマ ではカラフルな既成のデザインを選べ、カスタム では自分で作れます。エディターが色の読みやすさをチェックしてくれます。
  • サーバーでのデフォルトテーマ：サーバー独自のテーマを使うか、常に自分のテーマを使うか。
  • アクセントカラー、チャットの文字サイズ、ズームレベル。
  • メッセージの表示：アバターと余白のある ゆったり、または画面に多くのメッセージを表示する コンパクト。UIの密度 も選べます。
  • ロールの色：名前に付ける、名前の横に表示する、表示しない、から選べます。
  • デバイス間で設定を同期 すると、どこでも同じ外観になります。

#アクセシビリティ

  • 動きを減らす でアニメーションを抑えます。ハイコントラスト と 彩度 は読みやすさを助けます。
  • オン/オフのインジケーターを表示 するとスイッチに ✓ と ✗ が付きます。リンクに常に下線を表示 もあります。
  • アニメーション絵文字、GIF、スタンプ、凝った名前のスタイルをいつ再生するかを選べます。
  • 読み上げ速度 と 時刻形式（12時間制または24時間制）。

#音声、チャット、通知

  • 音声・ビデオ：マイク、スピーカー、カメラ、プッシュトゥトーク、ノイズ抑制。ボイスとビデオをご覧ください。
  • チャット：リンクのプレビュー、画像の表示サイズ、絵文字の候補、ネタバレをいつ表示するか、そして自分だけのアニメーション付き 入力中インジケーター。
  • 通知：通知をご覧ください。
  • キー割り当て：キーボードショートカットをご覧ください。

#言語

Parleyは、英語、スペイン語、ドイツ語、フランス語、イタリア語、オランダ語、ポーランド語、ポルトガル語（ブラジル）、ロシア語、トルコ語、アラビア語、日本語、韓国語、中国語（簡体字）に対応しています。システムに合わせる を選ぶと、デバイスの言語に従います。各言語には、どれくらい翻訳されているかが表示されます。

#配信者モード

配信や画面共有をしますか？配信者モード は、個人情報や招待リンクを隠し、サウンドや通知を止めることもできます。デスクトップアプリでは、OBS、Streamlabs、XSplitの実行中に自動でオンにできます。Ctrl+Shift+X で切り替えられます。

#クリップ

クリップを有効にする と、キー1つで通話の直前の場面を保存できます。クリップは自分のデバイス上で録画され、ここでダウンロードや削除ができます。ボイスとビデオをご覧ください。

#詳細設定

  • 開発者モード をオンにすると、メニューに IDをコピー が追加されます。Botによっては、このIDを求められることがあります。
  • デスクトップアプリのみ：
    • パソコンの起動時に開始、最小化した状態で開始、閉じる・最小化するとトレイに格納
    • ゲーム内オーバーレイ
    • ハードウェアアクセラレーション
    • アプリのアップデート：安定版 チャンネル（リリースのみ）か 開発版（すべての新しいビルド。冒険したい人向け）を選べます
