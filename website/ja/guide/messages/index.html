メッセージ

メッセージの入力、書式、メンション、リアクション、返信、ファイル添付、投票、予約、ブックマーク。

#メッセージを送る

下の入力欄に入力して Enter を押します。送信せずに改行するには Shift+Enter を押します。

  • 打ち間違えた？空の入力欄で ↑ を押すと、最後に送ったメッセージを編集できます。
  • 書きかけのメッセージはチャンネルごとに保存されます。後で戻ってきても下書きが残っています。
  • メッセージは最大2,000文字です。それより長いものは、ワンクリックでファイルとして送れます。

#書式

テキストを選択すると小さなツールバーが出ます：太字、斜体、下線、取り消し線、コード、ネタバレ。書式を自分で入力することもできます。

こう入力するとこうなります
**bold**太字
*italic*斜体
__underline__下線付きのテキスト
~~strike~~取り消し線付きのテキスト
` code `code
`\\spoiler\\`クリックするまで隠れるテキスト
# Big heading（##、### も）見出し
-# small print小さな灰色のテキスト
> quote引用（>>> はそれ以降すべてを引用）
- item または 1. itemリスト
[text](https://…)好きなテキストを付けたリンク

コードのブロックを書くには、前の行と後ろの行にバッククォートを3つ置きます。最初の3つの後ろに言語名を付けると（` `python `）色が付きます。コードブロックには コピー ボタンが付きます。

キーボードショートカットも使えます：Ctrl+B で太字、Ctrl+I で斜体、Ctrl+U で下線、Ctrl+E でコード。

#メンション

  • @ に続けて名前を入力すると、その人をメンションできます。相手に通知が届き、メッセージがハイライトされます。
  • @ ではロールも探せます。ほかに @everyone（チャンネルの全員）と @here（オンラインの全員）もあります。これらを誰が使えるかはサーバーが決めます。
  • # を入力するとチャンネルへのリンクを入れられます。

↑ と ↓ で候補を選び、Enter か Tab で決定します。

#絵文字、スタンプ、GIF

メッセージ入力欄の右にある3つのボタンで、GIF、スタンプ、絵文字 のピッカーが開きます。

  • 絵文字： 検索、よく使う絵文字、各サーバーのカスタム絵文字、肌の色の選択。:tada のように : と名前を入力して、リストから選ぶこともできます。
  • Parleyはどのデバイスでも同じスタイルで絵文字を表示するので、パソコン自体の絵文字が古くても、国旗を含めて全員に同じものが見えます。
  • 参加しているどのサーバーの カスタム絵文字 も、投稿できる場所ならどこでも使えます。メッセージ内の絵文字をクリックすると、どこのものかわかります。
  • スタンプ は参加しているサーバーのものが使えます。
  • GIF： 検索、トレンド、カテゴリー。GIFにカーソルを合わせて星をクリックすると、お気に入り に保存できます。

#リアクション

メッセージにカーソルを合わせてよく使う絵文字から選ぶか、リアクションを追加 をクリックしてすべての絵文字から選びます。スーパーリアクションを追加 では、アニメーション付きのリアクションを付けられます。

メッセージの下のリアクションをクリックすると自分も追加でき、もう一度クリックすると取り消せます。リアクションにカーソルを合わせると誰がリアクションしたかがわかります。メッセージのメニューから リアクションを表示 を選んでも見られます。

#返信、編集、削除

  • 返信 すると、元のメッセージが自分のメッセージの上に引用され、送信者に通知が届きます。Esc でキャンセルできます。
  • メッセージを編集 で、書いた内容を変更できます。編集したメッセージには （編集済み） と表示されます。それをクリックすると以前の版が見られます。
  • メッセージを削除 すると、全員の画面から消えます。

返信の上にある引用行をクリックすると、返信先のメッセージが表示されます。下部のバーの 戻る、または Esc で元の場所に戻れます。

#メッセージメニュー

メッセージを右クリックするか、⋯ ボタンをクリックするか、スマートフォンでは長押しします。次の項目があります。

  • 返信、転送、スレッドを作成
  • テキストをコピー と メッセージリンクをコピー
  • メッセージをピン留め。ピン留めは上部バーのピンボタン（Ctrl+P）に一覧表示されます。
  • メッセージをブックマーク：受信トレイに保存して後で読めます
  • リマインド：20分後、1時間後、3時間後、明日、来週
  • 未読にする：後で戻ってくるために
  • 翻訳（サーバーが提供している場合）と、読み上げで聞ける メッセージを読み上げる
  • 埋め込みを削除：リンクのプレビューを隠します
  • メッセージを報告：ルール違反を見つけたときに

#ファイル、画像、動画

+ をクリックして ファイルをアップロード を選ぶか、ファイルをチャットにドラッグするか、貼り付けます。

  • 1つのメッセージに最大10ファイル、通常は1ファイル25 MBまでです。サーバーの運営者がもっと大きな上限にしている場合もあります。
  • 送信前に ネタバレとしてマーク したり、代替テキストを追加 したりできます。代替テキストは、スクリーンリーダーを使う人のための説明です。
  • 画像はクリックすると原寸大で開きます。動画と音声はチャットの中でそのまま再生されます。

#ボイスメッセージ

+ をクリックして ボイスメッセージを録音 を選びます。話し終えたら、送信するか破棄します。聞く人は1.5倍や2倍の速度で再生できます。サーバーで文字起こしがオンになっていれば、読むこともできます。

#投票

+ をクリックして 投票を作成 を選びます。

  1. 質問と、2〜10個の回答を書きます。回答にはそれぞれ絵文字を付けられます。
  2. 複数の回答を選べるようにするかどうかを決めます。
  3. 期間を1時間〜1週間、または無期限から選びます。
  4. 投票を投稿 をクリックします。

結果はリアルタイムで更新されます。投票を作った人は早めに締め切ることもできます。

#メッセージを予約する

メッセージを書いたら、送信 ボタンを右クリック（スマートフォンでは長押し）して メッセージを予約 を選びます。明日の朝 などの時刻を選ぶか、カスタム を選びます。

予約メッセージは最大30件まで設定できます。受信トレイの 予約済み で確認でき、そこで 今すぐ送信、編集、削除ができます。

#転送

転送 すると、メッセージのコピーをほかのチャンネルや人に送れます。転送済み のラベルが付き、元のメッセージが削除されても残ります。

#スラッシュコマンド

入力欄の先頭で / を入力すると、使えるコマンドが表示されます。

コマンド動作
/shrug /tableflip /unflip /lennyメッセージに顔文字を付けます
/meメッセージを行動として斜体で送ります
/spoilerメッセージ全体をクリックするまで隠します
/ttsチャンネルを見ている全員にメッセージを読み上げます
/nickこのサーバーでのニックネームを変更します

サーバーのアプリやBotは、独自のコマンドを追加します。アプリとBotをご覧ください。

#要約

チャンネルが盛り上がりすぎ？上部バーの 要約 ボタンで、ここ数日の流れをすばやくまとめて見られます。要約は自動で作られるので、頼る前に元のメッセージを確認してください。サーバーはこの機能をオフにできます。
